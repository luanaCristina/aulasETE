🪟 1. Instalação no Windows

1

Acesse o site oficial do MySQL

Abra o navegador e vá para: https://dev.mysql.com/downloads/installer/

2

Baixe o MySQL Installer for Windows

Escolha o arquivo mysql-installer-community (o maior, offline).

📸 Screenshot: Página de download do MySQL Installer
3

Execute o instalador

Dê duplo clique no arquivo baixado e permita a execução como administrador.

4

Escolha "Custom" para selecionar os componentes

Marque apenas:

  • ✓ MySQL Server 8.x
  • ✓ MySQL Workbench
📸 Screenshot: Tela de seleção "Custom" no instalador
5

Configure a senha do root

Defina uma senha segura. Exemplo: root123

⚠️

ANOTE A SENHA!

Se esquecer a senha do root, terá que reinstalar o MySQL completamente. Anote em um lugar seguro!

6

Porta padrão: 3306

Mantenha a porta padrão 3306. Não altere a menos que necessário.

7

Finalize a instalação

Clique "Next" até concluir. O instalador configurará o serviço automaticamente.

8

Abra o MySQL Workbench

Procure "MySQL Workbench" no Menu Iniciar e abra o programa.

9

Teste a conexão

Clique em "Local instance MySQL" → digite a senha do root → se conectar, está funcionando!

📸 Screenshot: Tela inicial do MySQL Workbench com conexão local
✅

Pronto!

Se conseguiu conectar, o MySQL está instalado e funcionando corretamente no Windows!

🍎 2. Instalação no macOS

Opção A: Via Homebrew (Recomendado)

💡

Homebrew é o jeito mais fácil!

Se você ainda não tem o Homebrew, instale antes: brew.sh

1

Instale o MySQL via Terminal

brew install mysql
2

Inicie o serviço

brew services start mysql
3

Configure a segurança (definir senha root)

mysql_secure_installation

Siga as instruções para definir a senha do root e configurar opções de segurança.

Opção B: Via DMG do Site Oficial

1

Acesse o site

https://dev.mysql.com/downloads/mysql/

2

Baixe o DMG correto para seu Mac

  • • Apple Silicon (M1/M2/M3): ARM, 64-bit
  • • Intel: x86, 64-bit
3

Instale o MySQL Server

Abra o DMG e siga o assistente de instalação. Anote a senha temporária gerada!

4

Inicie o serviço

Abra System Preferences (Ajustes do Sistema) → MySQL → Start Server

📸 Screenshot: Painel MySQL nas Preferências do Sistema

Instalar o Workbench separadamente

1

Baixe o Workbench

https://dev.mysql.com/downloads/workbench/

2

Instale arrastando para Applications

Abra o DMG baixado e arraste o ícone do MySQL Workbench para a pasta Applications.

3

Teste no terminal

mysql -u root -p

Se pedir a senha e conectar, está tudo certo!

🔌 3. Configurando a Conexão no Workbench

1

Abra o MySQL Workbench

Na tela inicial, você verá a área "MySQL Connections".

📸 Screenshot: Tela inicial do Workbench com área de conexões
2

Clique no "+" ao lado de "MySQL Connections"

Isso abre a janela de configuração de nova conexão.

3

Preencha os dados da conexão

Connection Name: PetShop Local
Hostname: 127.0.0.1
Port: 3306
Username: root
📸 Screenshot: Janela "Setup New Connection" preenchida
4

Teste a conexão

Clique "Test Connection" → digite a senha do root → clique "OK".

5

Salve a conexão

Clique "OK" para salvar a conexão.

6

Conecte ao banco

Dê duplo clique na conexão "PetShop Local" criada para abrir o editor SQL.

Dica

Se aparecer "Connection successful", você está pronto para trabalhar!

1

Expanda o schema petshop

2

Clique com botão direito em "Tables" → "Create Table..."

3

Nome da tabela: cliente

4

Adicione as colunas:

Column Name Datatype PK NN AI
id INT ✅ ✅ ✅
nome VARCHAR(100) — ✅ —

PK = Primary Key | NN = Not Null | AI = Auto Increment

5

Clique "Apply" → Revise o SQL → "Apply"

📸 Screenshot: Editor visual de tabela com colunas preenchidas

Mesmo processo: botão direito em "Tables" → "Create Table..."

💻 7. Criando com Comandos SQL (Editor de Query)

1

Abra um novo Query Tab

Na conexão aberta, clique em File → New Query Tab (ou Ctrl+T / Cmd+T)

2

Cole o código abaixo e execute com ⚡

Selecione todo o texto e clique no raio, ou use Ctrl+Shift+Enter / Cmd+Shift+Enter

petshop.sql 
-- ============================================
-- 🐬 PETSHOP - Script Completo
-- ============================================

-- Criar o banco
CREATE DATABASE IF NOT EXISTS petshop;
USE petshop;

-- ============================================
-- CRIAR TABELAS
-- ============================================

CREATE TABLE cliente (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(100) NOT NULL,
  telefone VARCHAR(20),
  email VARCHAR(100)
);

CREATE TABLE veterinario (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(100) NOT NULL,
  crmv VARCHAR(20) NOT NULL
);

CREATE TABLE pet (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(50) NOT NULL,
  especie VARCHAR(30),
  raca VARCHAR(50),
  cliente_id INT NOT NULL,
  FOREIGN KEY (cliente_id) REFERENCES cliente(id)
);

CREATE TABLE consulta (
  id INT AUTO_INCREMENT PRIMARY KEY,
  data DATE NOT NULL,
  diagnostico TEXT,
  cliente_id INT NOT NULL,
  pet_id INT NOT NULL,
  vet_id INT NOT NULL,
  FOREIGN KEY (cliente_id) REFERENCES cliente(id),
  FOREIGN KEY (pet_id) REFERENCES pet(id),
  FOREIGN KEY (vet_id) REFERENCES veterinario(id)
);

🔧 8. Dicas e Resolução de Problemas

❌

"Access denied for user 'root'@'localhost'"

Solução: Verifique se a senha está correta. Tente digitar novamente com cuidado (sem espaços antes/depois).

❌

"Can't connect to MySQL server"

Solução: O serviço MySQL não está rodando. Inicie-o:

macOS (Homebrew):

brew services start mysql

Windows:

Services → MySQL80 → Start
❌

"Port 3306 already in use"

Solução: Outra instância do MySQL (ou outro programa) está usando a porta. Verifique:

macOS/Linux:

lsof -i :3306

Windows (CMD como Admin):

netstat -ano | findstr 3306
⚠️

Esqueceu a senha do root?

Windows: Reinstale o MySQL ou siga o guia de reset no site oficial.

macOS (Homebrew):

brew services stop mysql
mysqld_safe --skip-grant-tables &
mysql -u root
-- Dentro do MySQL:
ALTER USER 'root'@'localhost' IDENTIFIED BY 'novaSenha123';
💡

Dicas gerais

  • • Sempre termine comandos SQL com ;
  • • Use Ctrl+Z / Cmd+Z no editor para desfazer
  • • O Workbench salva automaticamente o histórico de queries
  • • Para ver estrutura da tabela: clique com botão direito → "Table Inspector"
