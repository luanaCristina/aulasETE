## REVISÃO AV1 — Princípios de Design

### Resumo: CRAP (4 Princípios)
- **C**ontraste — Destaque o que é importante (tamanho, cor, peso)
- **R**epetição — Consistência visual (mesmos estilos se repetem)
- **A**linhamento — Tudo tem conexão visual (nada solto)
- **P**roximidade — Itens relacionados ficam juntos

### Cores e Tipografia
- Paleta: max 5 cores (primária, secundária, acento, neutras)
- Contraste mínimo WCAG: 4.5:1 para texto normal
- Fontes: máximo 2 famílias (título sans-serif + corpo serif ou vice-versa)
- Tamanho mínimo: 16px para corpo de texto

### Exercícios (5)
1. Analisar print de app — identificar qual princípio CRAP está fraco
2. Criar paleta de 5 cores para app de saúde + justificar
3. Escolher 2 fontes Google Fonts que harmonizam — mostrar uso
4. Redesenhar cartão de visita ruim aplicando os 4 princípios
5. Verificar contraste de 3 combinações cor texto/fundo no WebAIM

## REVISÃO AV2 — Figma + Protótipo

### Checklist do Projeto Figma
- [ ] Frames nos tamanhos corretos (375px mobile)
- [ ] Auto Layout para espaçamento consistente
- [ ] Componentes criados (botão, input, card)
- [ ] Variantes de componente (primário, secundário, disabled)
- [ ] Protótipo: conexões entre telas (Navigate to)
- [ ] Smart Animate para transições suaves

### Erros Comuns no Figma
1. Não usar Auto Layout → espaçamento inconsistente
2. Cores hardcoded → usar Styles/Variables
3. Texto com tamanho fixo → usar Fill para ser responsivo
4. Ignorar estados (hover, pressed, disabled)

## REVISÃO AV3 — Prova Final UX

### Conceitos-Chave
- **UI** = como parece (visual, cores, ícones)
- **UX** = como funciona (fluxo, facilidade, satisfação)
- **Wireframe** = esqueleto (low-fi, sem cor/estilo)
- **Mockup** = visual final (high-fi, com cores/imagens)
- **Protótipo** = mockup clicável (simula navegação)
- **Design System** = biblioteca de componentes reutilizáveis
- **Teste de Usabilidade** = observar usuário usando o app
