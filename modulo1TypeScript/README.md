# Módulo I — TypeScript Version

## Projeto: Feira Criativa Recife (Express + EJS + TypeScript)

```bash
npm install
npm run dev   # http://localhost:5000
```

### Estrutura
```
modulo1TypeScript/
├── src/
│   ├── server.ts, app.ts
│   ├── routes/index.ts
│   ├── models/ (Artesao.ts, Contato.ts)
│   └── services/ (artesaoService.ts, contatoService.ts)
├── views/index.ejs
├── public/ (css, js)
├── data/ (artesaos.json, contatos.json)
├── package.json, tsconfig.json
```
