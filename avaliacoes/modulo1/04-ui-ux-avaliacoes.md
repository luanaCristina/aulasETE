# 📝 Avaliações — Design de Interface (UI/UX)

> **Módulo:** I | **Carga Horária:** 40h

---

## AVALIAÇÃO 1 — Diagnóstica (Peso: 20%)

**Duração:** 60 min | **Conteúdo:** Princípios de design, tipografia, cores

### Q1 (30 pts): Análise de Interface
Analisar print de app real identificando: hierarquia visual, uso de cores,
tipografia, espaçamento, problemas de UX. Mínimo 5 pontos positivos e 3 negativos.

### Q2 (40 pts): Paleta e Tipografia
Criar design system mínimo no Figma: paleta de 5 cores (primária, secundária,
sucesso, erro, neutra) com justificativa + 2 fontes escolhidas.

### Q3 (30 pts): Princípios CRAP
Identificar qual dos 4 princípios (Contraste, Repetição, Alinhamento, Proximidade)
está sendo violado em 4 layouts dados e propor correção.

---

## AVALIAÇÃO 2 — Projeto Prático (Peso: 40%)

### Projeto: Protótipo de App Completo no Figma

Criar protótipo de alta fidelidade para app de delivery de comida:
- Mínimo 5 telas (splash, login, home, busca, carrinho, detalhe)
- Design system com componentes (botões, inputs, cards)
- Protótipo clicável (navegação entre telas)
- Versão mobile (375px)

**Rubrica (100 pts):**
| Critério | Pontos |
|----------|--------|
| 5+ telas com conteúdo real | 20 |
| Design system (5+ componentes) | 20 |
| Hierarquia visual clara | 15 |
| Consistência (cores, fontes, espaços) | 15 |
| Protótipo clicável funcional | 15 |
| Acessibilidade (contraste, tamanhos) | 15 |

---

## AVALIAÇÃO 3 — Prova Final (Peso: 40%)

### Parte A — Conceitual (40 pts)
1. Diferença entre UI e UX (com exemplos)
2. O que é Mobile-First no design? Por que adotar?
3. Como conduzir um teste de usabilidade? (5 passos)
4. O que é um Design System e por que empresas usam?

### Parte B — Prática (60 pts)
Redesign: receber print de site ruim → criar wireframe + mockup melhorado
no Figma em 60 min. Justificar 3 decisões de design.
