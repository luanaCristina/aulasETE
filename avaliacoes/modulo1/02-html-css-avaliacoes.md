# 📝 Avaliações — Introdução ao Desenvolvimento Web (HTML5/CSS3)

> **Módulo:** I | **Carga Horária:** 60h

---

## AVALIAÇÃO 1 — Diagnóstica (Peso: 20%)

**Duração:** 60 min | **Conteúdo:** HTML semântico + formulários

### Q1 (40 pts): Criar página "Currículo Online"
Criar página HTML5 válida com: header (nome + foto), nav, section experiência
(lista ordenada), section habilidades (lista não-ordenada), formulário de contato
(5 campos variados), footer. Usar apenas tags semânticas.

### Q2 (30 pts): Corrigir HTML
Código dado com 10 erros (tags não fechadas, img sem alt, form sem labels,
h3 antes de h2, div onde deveria ser section). Aluno identifica e corrige.

### Q3 (30 pts): Formulário Acessível
Criar form de cadastro com: text, email, password, date, select, radio, checkbox,
textarea. Todos com label, placeholder, required onde necessário.

**Rubrica:** Semântica (30%) + Formulários corretos (40%) + Acessibilidade (30%)

---

## AVALIAÇÃO 2 — Projeto Prático (Peso: 35%)

**Duração:** 4h | **Conteúdo:** Flexbox + Grid + Responsividade

### Projeto: Replicar Layout de E-commerce

Dado um mockup (imagem) de página de produtos, o aluno deve replicar usando:
- Header com logo + nav (Flexbox)
- Grid de cards de produtos (CSS Grid, 1/2/3 colunas por breakpoint)
- Sidebar de filtros (Flexbox vertical)
- Footer com 4 colunas (Grid)
- Mobile-first com 3 breakpoints

**Rubrica (100 pts):**
| Critério | Pontos |
|----------|--------|
| Header Flexbox funcional | 15 |
| Grid de produtos responsivo | 25 |
| Cards estilizados (sombra, radius, hover) | 15 |
| Sidebar de filtros | 10 |
| Footer em grid | 10 |
| Mobile-first (base = mobile) | 15 |
| Sem scroll horizontal em nenhuma tela | 10 |

## AVALIAÇÃO 3 — Prova Final (Peso: 45%)

### Parte A — Conceitual (30 pts)
1. (6 pts) Diferença entre Flexbox e Grid. Quando usar cada?
2. (6 pts) O que é Box Model? Quais as 4 partes?
3. (6 pts) O que significa "Mobile-First"? Como se implementa no CSS?
4. (6 pts) Cite 3 práticas de acessibilidade em HTML/CSS.
5. (6 pts) Para que serve `box-sizing: border-box`?

### Parte B — Prática (70 pts)
Criar landing page responsiva com 4 seções em 90 minutos.
Avaliar: semântica, Flexbox/Grid, responsividade, acessibilidade.
