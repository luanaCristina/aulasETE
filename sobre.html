ℹ️ Sobre o site

Portal de aulas do Curso Técnico Subsequente em Desenvolvimento de Sistemas — ETE Pernambuco.

O que é

Este site reúne, em um só lugar, os materiais das disciplinas do curso, organizados em três módulos (Fundação, Evolução Web e Consolidação). Cada disciplina tem uma apresentação em slides, com explicações, exemplos de código, exercícios e desafios. Os materiais são produzidos e mantidos pela Profª Luana Cristina.

Para que pode ser usado

  • Acompanhar as aulas: abrir os slides durante a aula, no computador ou no celular.
  • Estudar e revisar: rever o conteúdo no seu ritmo, incluindo quizzes e revisões.
  • Praticar: fazer exercícios de SQL, Python, JavaScript e APIs, com guias passo a passo.
  • Configurar o ambiente: seguir os guias de instalação de ferramentas (MySQL, PostgreSQL, Python, Node.js e outras).
  • Consultar projetos: encontrar orientações dos projetos integradores e de conclusão de curso.

Como navegar nos slides

Setas ← → para avançar e voltar · tecla F para tela cheia · tecla M para o menu · deslize o dedo no celular.

Privacidade

O site mede a quantidade de acessos e quais páginas são mais visitadas, usando uma ferramenta que não utiliza cookies e não identifica visitantes individualmente. Esses dados servem apenas para melhorar o material.
