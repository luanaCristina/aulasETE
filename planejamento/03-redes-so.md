# 📘 Disciplina 3 — Fundamentos de Redes e Sistemas Operacionais

> **Carga Horária:** 40h | **Aulas:** 20 encontros de 2h

---

## AULAS 01-02 — Introdução a Redes: Como a Internet Funciona
**Objetivo:** Entender modelo cliente-servidor, DNS, IP, portas.
**Prática:** Usar ping, traceroute, nslookup no terminal.

## AULAS 03-04 — Modelo OSI e TCP/IP
**Objetivo:** Identificar as camadas e seus protocolos.
**Prática:** Capturar pacotes simples com Wireshark (demo do professor).

## AULAS 05-06 — Protocolos HTTP/HTTPS
**Objetivo:** Entender requisição/resposta, headers, status codes, HTTPS/TLS.
**Prática:** Inspecionar requisições no DevTools Network tab + curl.

## AULAS 07-08 — Endereçamento IP e Sub-redes
**Objetivo:** Calcular sub-redes básicas, entender IPv4 vs IPv6, NAT.
**Prática:** Exercícios de cálculo de sub-rede (classe C).

## AULAS 09-10 — Sistemas Operacionais: Conceitos e Linux Básico
**Objetivo:** Entender processos, memória, file system. Navegar no terminal Linux.
**Prática:** Comandos: ls, cd, mkdir, cp, mv, rm, cat, chmod, ps, top.

## AULAS 11-12 — Terminal Avançado e Shell Scripts
**Objetivo:** Pipes, redirecionamento, variáveis de ambiente, scripts .sh.
**Prática:** Script que faz backup de uma pasta com data no nome.

## AULAS 13-14 — Gerenciamento de Pacotes e Serviços
**Objetivo:** apt/brew, systemctl, cron jobs.
**Prática:** Instalar Node.js via terminal, criar cron job simples.

## AULAS 15-16 — SSH e Acesso Remoto
**Objetivo:** Configurar chaves SSH, acessar servidor remoto.
**Prática:** Gerar par de chaves, configurar SSH para GitHub.

## AULAS 17-18 — Firewalls, Portas e Segurança de Rede
**Objetivo:** Conceitos de firewall, portas abertas, UFW básico.
**Prática:** Listar portas abertas (netstat/ss), configurar regra UFW.

## AULAS 19-20 — Avaliação Final + Exercício Prático
**Avaliação:** Quiz teórico (40%) + prática no terminal (60%):
criar usuário, configurar permissões, rodar servidor na porta X.
