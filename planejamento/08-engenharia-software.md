# 📘 Disciplina 8 — Engenharia de Software I (Agile/Requisitos)

> **Carga Horária:** 40h | **Aulas:** 20 encontros de 2h

---

## AULAS 01-02 — O que é Engenharia de Software
**Objetivo:** Entender o ciclo de vida do software e por que processos importam.
**Prática:** Analisar caso de falha de software famoso (Therac-25 ou Healthcare.gov).

## AULAS 03-04 — Metodologias: Cascata vs Ágil
**Objetivo:** Comparar Waterfall e Agile, entender quando usar cada.
**Prática:** Simular planejamento de projeto nos dois modelos (tabela comparativa).

## AULAS 05-06 — Scrum: Papéis, Eventos e Artefatos
**Objetivo:** PO, SM, Dev Team, Sprint, Daily, Review, Retro, Backlog.
**Prática:** Simular Sprint Planning com Product Backlog dado pelo professor.

## AULAS 07-08 — Kanban e Scrumban
**Objetivo:** Quadro Kanban, WIP limits, fluxo contínuo.
**Prática:** Configurar board no GitHub Projects para projeto fictício.

## AULAS 09-10 — User Stories e Critérios de Aceite
**Objetivo:** Escrever US no formato "Como... Quero... Para...".
**Prática:** Escrever 10 user stories para app de delivery + critérios INVEST.

## AULAS 11-12 — Requisitos Funcionais e Não-Funcionais
**Objetivo:** Documentar RF, RNF, regras de negócio.
**Prática:** Documento de requisitos para sistema de agendamento (formato estruturado).

## AULAS 13-14 — Diagramas UML: Casos de Uso e Classes
**Objetivo:** Desenhar diagrama de casos de uso e de classes (básico).
**Prática:** UML para sistema de biblioteca.

## AULAS 15-16 — Estimativa e Priorização (Story Points, MoSCoW)
**Objetivo:** Estimar complexidade e priorizar backlog.
**Prática:** Planning Poker com backlog real da turma.

## AULAS 17-18 — Git Flow e Code Review
**Objetivo:** Branches (feature, develop, main), PR, review.
**Prática:** Simular Git Flow em duplas com PR e review.

## AULAS 19-20 — Projeto: Documentação Completa de um Sistema
**Entrega:** Documento com: requisitos, user stories, UML, backlog priorizado.
