# 📘 Disciplina 13 — Desenvolvimento Mobile

> **Carga Horária:** 60h | **Aulas:** 30 encontros de 2h  
> **Framework:** React Native (Expo)

---

## AULAS 01-02 — Introdução ao Mobile: Nativo vs Híbrido vs Cross-Platform
**Objetivo:** Entender as abordagens, por que React Native, instalar Expo.
**Prática:** Criar projeto com `npx create-expo-app`, rodar no celular via Expo Go.

## AULAS 03-04 — Componentes Básicos: View, Text, Image, Button
**Objetivo:** JSX no mobile, estilização com StyleSheet.
**Prática:** Tela de perfil com foto, nome e lista de informações.

## AULAS 05-06 — Estilização: Flexbox no Mobile
**Objetivo:** flexDirection (column default), alignItems, justifyContent.
**Prática:** Layout de card de produto + lista horizontal de categorias.

## AULAS 07-08 — Listas: FlatList e ScrollView
**Objetivo:** Renderizar listas performáticas com FlatList.
**Prática:** Tela de feed com 50 items + pull-to-refresh.

## AULAS 09-10 — Navegação: React Navigation (Stack + Tab)
**Objetivo:** Stack Navigator para telas e Tab Navigator para menu inferior.
**Prática:** App com 3 tabs (Home, Busca, Perfil) + navegação entre telas.

## AULAS 11-12 — Formulários e Inputs no Mobile
**Objetivo:** TextInput, Switch, Picker + validação.
**Prática:** Tela de cadastro completa com validação em tempo real.

## AULAS 13-14 — Estado e Hooks: useState, useEffect
**Objetivo:** Gerenciar estado local e efeitos colaterais.
**Prática:** Tela de contador + timer + fetch de dados no mount.

## AULAS 15 — AVALIAÇÃO A1 (Componentes + Navegação + Estado)

## AULAS 16-18 — Consumindo API REST no Mobile
**Objetivo:** fetch/axios + loading + error handling no mobile.
**Prática:** Lista de produtos da API do módulo 9 + tela de detalhe.

## AULAS 19-20 — Geolocalização (expo-location)
**Objetivo:** Pedir permissão, obter coordenadas, usar com mapa.
**Prática:** "Onde estou?" — exibir lat/long + endereço reverso.

## AULAS 21-22 — Câmera e Galeria (expo-camera / image-picker)
**Objetivo:** Tirar foto ou escolher da galeria, enviar para API.
**Prática:** Tela de "escanear QR" ou "enviar foto de perfil".

## AULAS 23-24 — AsyncStorage: Persistência Local
**Objetivo:** Salvar dados offline (token, preferências).
**Prática:** Login que persiste token + tela que funciona offline.

## AULAS 25-26 — Notificações Push (expo-notifications)
**Objetivo:** Configurar push notifications locais e remotas.
**Prática:** Lembrete agendado que dispara notificação.

## AULAS 27-28 — Publicação: EAS Build + App Stores
**Objetivo:** Gerar APK/IPA, conceito de publicação nas stores.
**Prática:** Build de APK com `eas build --platform android`.

## AULAS 29-30 — Projeto Final: App Completo
**Tema:** App de coleta seletiva (EcoColeta) integrando com API.
**Requisitos:** 5+ telas, navegação, API, geolocalização ou câmera, AsyncStorage.
