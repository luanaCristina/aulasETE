# 📘 Disciplina 7 — Desenvolvimento Web Front-End (JavaScript)

> **Carga Horária:** 60h | **Aulas:** 30 encontros de 2h  
> **Foco:** DOM, eventos, Fetch API, armazenamento local

---

## AULAS 01-02 — JavaScript no Navegador: DOM
**Objetivo:** Selecionar e manipular elementos HTML com JS.
**Prática:** Trocar textos, cores e visibilidade de elementos dinâmicamente.

## AULAS 03-04 — Eventos: click, submit, keyup, change
**Objetivo:** Registrar event listeners e responder a ações do usuário.
**Prática:** Formulário que valida em tempo real (keyup) e exibe feedback.

## AULAS 05-06 — Criação Dinâmica de Elementos
**Objetivo:** createElement, appendChild, innerHTML, template literals.
**Prática:** Lista de tarefas que adiciona/remove items no DOM.

## AULAS 07-08 — Projeto Mini: Todo List Completo
**Objetivo:** CRUD completo no DOM (criar, ler, editar, deletar, marcar).
**Prática:** To-Do List com filtros (todas, ativas, concluídas).

## AULAS 09-10 — LocalStorage e SessionStorage
**Objetivo:** Persistir dados no navegador entre recarregamentos.
**Prática:** Todo List com dados salvos no localStorage.

## AULAS 11-12 — Funções Assíncronas: Callbacks e Promises
**Objetivo:** Entender assincronismo, callback hell, Promise.
**Prática:** Simular delays com setTimeout + converter para Promise.

## AULAS 13-14 — Async/Await e Fetch API
**Objetivo:** Consumir APIs REST com fetch e async/await.
**Prática:** App que busca CEP na API ViaCEP e exibe endereço.

## AULAS 15 — AVALIAÇÃO A1 (DOM + Eventos + LocalStorage)

## AULAS 16-18 — Consumindo APIs: Listagem e Busca
**Objetivo:** GET com parâmetros, loading state, tratamento de erros.
**Prática:** App que consome PokeAPI ou IBGE (lista + busca + detalhe).

## AULAS 19-20 — Enviando Dados: POST, PUT, DELETE
**Objetivo:** Enviar JSON para API, tratar respostas 201, 400, 500.
**Prática:** CRUD completo consumindo API jsonplaceholder.

## AULAS 21-22 — Modularização: ES Modules
**Objetivo:** import/export, organizar código em módulos.
**Prática:** Refatorar projeto em módulos (api.js, ui.js, utils.js).

## AULAS 23-24 — Web Components Básicos
**Objetivo:** Custom Elements, Shadow DOM (conceito), templates.
**Prática:** Criar componente `<user-card>` reutilizável.

## AULAS 25-26 — Performance e Boas Práticas
**Objetivo:** Debounce, lazy loading, código limpo no front.
**Prática:** Otimizar app com debounce na busca + lazy load de imagens.

## AULAS 27-28 — Projeto Final: SPA Simples
**Objetivo:** Single Page Application com múltiplas "páginas" (hash routing).
**Prática:** App de filmes (TMDB API) com home, busca e detalhe.
