# 📘 Disciplina 2 — Introdução ao Desenvolvimento Web (HTML5/CSS3)

> **Carga Horária:** 60h | **Aulas:** 30 encontros de 2h  
> **Projeto Final:** Landing Page responsiva publicada no GitHub Pages

---

## 📅 Cronograma

| Bloco | Aulas | Tema |
|-------|-------|------|
| 1 | 01-06 | HTML5 Semântico: estrutura, tags, formulários |
| 2 | 07-12 | CSS3 Básico: seletores, box model, tipografia, cores |
| 3 | 13-18 | Layout: Flexbox e Grid |
| 4 | 19-24 | Responsividade: Mobile-First e Media Queries |

---

## AULAS 01-02 — Introdução à Web e Estrutura HTML

**Objetivo:** Entender como a web funciona (cliente-servidor) e criar documento HTML válido.
**Teoria:** HTTP, navegador, tags básicas (html, head, body, h1-h6, p, a, img, ul/ol/li)
**Prática:** Criar página "Sobre Mim" com título, parágrafos, lista de habilidades, foto e links.
**Gabarito:** Estrutura HTML5 completa com doctype, meta viewport, charset, lang pt-BR.

## AULAS 03-04 — HTML Semântico e Estruturação

**Objetivo:** Usar tags semânticas (header, nav, main, section, article, aside, footer).
**Prática:** Reestruturar a página "Sobre Mim" usando tags semânticas corretas.

## AULAS 05-06 — Formulários HTML e Validação Nativa

**Objetivo:** Criar formulários com inputs variados e atributos de validação.
**Prática:** Formulário de cadastro (text, email, tel, password, radio, checkbox, select, textarea).
**Gabarito:** Form com required, pattern, minlength, type=email.

## AULAS 07-08 — CSS: Seletores, Cores e Tipografia

**Objetivo:** Vincular CSS ao HTML, usar seletores e estilizar texto.
**Prática:** Estilizar a página "Sobre Mim" com paleta de cores e Google Fonts.

## AULAS 09-10 — Box Model e Espaçamentos

**Objetivo:** Dominar padding, margin, border, width, height e box-sizing.
**Prática:** Criar cards de produtos com espaçamento consistente.

## AULAS 11-12 — Posicionamento e Display

**Objetivo:** Entender static, relative, absolute, fixed, sticky + display block/inline/none.
**Prática:** Header fixo + menu de navegação estilizado.

## AULAS 13-14 — Flexbox (Parte 1)

**Objetivo:** Usar flex container e flex items para layouts unidimensionais.
**Prática:** Barra de navegação responsiva + galeria de cards em linha.
**Gabarito:** display:flex, justify-content, align-items, gap, flex-wrap.

## AULAS 15-16 — Flexbox (Parte 2) + Avaliação A1

**Objetivo:** Resolver layouts complexos com flex-grow/shrink/basis e order.
**A1:** Replicar um layout dado (imagem) usando apenas Flexbox (90 min).

## AULAS 17-18 — CSS Grid (Parte 1)

**Objetivo:** Criar layouts bidimensionais com grid-template-columns/rows e gap.
**Prática:** Layout de blog com sidebar, header, conteúdo e footer usando Grid.

## AULAS 19-20 — CSS Grid (Parte 2)

**Objetivo:** Usar grid-area, grid-template-areas e auto-fit/auto-fill.
**Prática:** Dashboard com cards de tamanhos variados (span 2 colunas, etc).

## AULAS 21-22 — Responsividade e Mobile-First

**Objetivo:** Implementar design mobile-first com media queries (min-width).
**Prática:** Transformar layout desktop fixo em responsivo (320px, 768px, 1024px).

## AULAS 23-24 — Imagens Responsivas e Unidades Relativas

**Objetivo:** Usar rem, em, vw, vh, %, clamp() e imagens com srcset.
**Prática:** Galeria de fotos que se adapta sem distorção.

## AULAS 25-26 — Acessibilidade (WCAG)

**Objetivo:** Implementar contraste, alt texts, focus, skip links, aria-labels.
**Prática:** Auditoria Lighthouse na própria página + correções.

## AULAS 27-28 — Animações e Transições CSS

**Objetivo:** Usar transition e @keyframes para microinterações.
**Prática:** Hover em cards, loading spinner, menu animado.

## AULAS 29-30 — Projeto Final + Deploy GitHub Pages

**Objetivo:** Landing page completa (mínimo 5 seções) publicada.
**Critérios:** Semântico + Responsivo + Acessível + 3 breakpoints + GitHub Pages.
