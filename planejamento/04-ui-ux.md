# 📘 Disciplina 4 — Design de Interface (UI/UX)

> **Carga Horária:** 40h | **Aulas:** 20 encontros de 2h  
> **Ferramenta:** Figma (gratuito)

---

## AULAS 01-02 — Introdução ao Design de Interfaces
**Objetivo:** Diferenciar UI de UX, conhecer o processo de design.
**Prática:** Analisar 3 apps populares identificando pontos fortes/fracos de UX.

## AULAS 03-04 — Princípios de Design Visual
**Objetivo:** Hierarquia, contraste, alinhamento, proximidade, repetição.
**Prática:** Redesenhar um cartão de visita aplicando os 4 princípios.

## AULAS 05-06 — Tipografia e Cores
**Objetivo:** Escolher fontes (sans/serif), criar paleta harmônica, contraste WCAG.
**Prática:** Definir design system mínimo: 2 fontes + paleta de 5 cores.

## AULAS 07-08 — Figma: Introdução e Wireframes
**Objetivo:** Navegar no Figma, criar frames, usar componentes básicos.
**Prática:** Wireframe low-fidelity de tela de login (mobile).

## AULAS 09-10 — Figma: Protótipo de Alta Fidelidade
**Objetivo:** Criar UI com estilo visual, ícones, imagens e espaçamento.
**Prática:** Transformar wireframe da aula anterior em mockup high-fidelity.

## AULAS 11-12 — Design Responsivo e Adaptativo
**Objetivo:** Breakpoints, grids de 12 colunas, auto layout no Figma.
**Prática:** Criar versão mobile + desktop da mesma tela no Figma.

## AULAS 13-14 — Pesquisa com Usuário e Personas
**Objetivo:** Criar persona, mapa de empatia e jornada do usuário.
**Prática:** Entrevistar 1 colega como "usuário" e criar persona.

## AULAS 15-16 — Componentes e Design System
**Objetivo:** Criar componentes reutilizáveis (botões, inputs, cards).
**Prática:** Montar mini design system com 5 componentes no Figma.

## AULAS 17-18 — Prototipação e Teste de Usabilidade
**Objetivo:** Criar protótipo clicável e conduzir teste com 1 usuário.
**Prática:** Protótipo de fluxo (login → home → detalhe) + teste com colega.

## AULAS 19-20 — Projeto Final: UI Completa de um App
**Critérios:** 5+ telas, design system, responsivo, protótipo clicável, apresentação.
