# 📘 Disciplina 14 — DevOps e Controle de Versão (Git/Docker)

> **Carga Horária:** 40h | **Aulas:** 20 encontros de 2h

---

## AULAS 01-02 — Git: Conceitos e Primeiros Comandos
**Objetivo:** init, add, commit, status, log, diff.
**Prática:** Criar repo local, fazer 5 commits com boas mensagens.

## AULAS 03-04 — GitHub: Remoto, Push, Pull, Clone
**Objetivo:** Conectar local ao GitHub, colaboração básica.
**Prática:** Push do projeto, README.md, configurar SSH.

## AULAS 05-06 — Branches e Merge
**Objetivo:** Criar branches, fazer merge, resolver conflitos.
**Prática:** Feature branch → merge → resolver conflito proposital.

## AULAS 07-08 — Git Flow e Pull Requests
**Objetivo:** Workflow profissional: feature/develop/main + PR + review.
**Prática:** Simular PR em dupla com code review no GitHub.

## AULAS 09-10 — Docker: Conceitos e Containers
**Objetivo:** Imagens vs containers, Dockerfile, docker run.
**Prática:** Dockerizar um "Hello World" Node.js.

## AULAS 11-12 — Dockerfile: Multi-stage e Best Practices
**Objetivo:** Multi-stage build, .dockerignore, layers eficientes.
**Prática:** Dockerfile otimizado para app TypeScript (build + prod).

## AULAS 13-14 — Docker Compose: Multi-Container
**Objetivo:** Orquestrar API + Banco + Redis com docker-compose.
**Prática:** docker-compose.yml para app completo (3 serviços).

## AULAS 15-16 — CI/CD: GitHub Actions
**Objetivo:** Criar pipeline automatizado (test + build + docker).
**Prática:** .github/workflows/ci.yml que roda testes no push.

## AULAS 17-18 — Deploy: Plataformas e Estratégias
**Objetivo:** Render, Railway, Fly.io, AWS free tier — conceitos de deploy.
**Prática:** Deploy de API no Render (free tier) via GitHub.

## AULAS 19-20 — Projeto Final: Pipeline Completo
**Entrega:** Repo com: Dockerfile, docker-compose, CI/CD, deploy funcional.
