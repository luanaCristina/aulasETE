# 📘 Disciplina 15 — Projeto Integrador / TCC

> **Carga Horária:** 80h | **Aulas:** 40 encontros de 2h  
> **Formato:** Projeto em equipe (3-5 alunos) com entregas quinzenais

---

## FASE 1: PLANEJAMENTO (Aulas 01-10)

### AULAS 01-02 — Formação de Equipes e Brainstorming
**Objetivo:** Formar grupos, escolher tema com impacto social/local.
**Entrega:** Documento de 1 página: problema, solução proposta, equipe.

### AULAS 03-04 — Pesquisa e Validação da Ideia
**Objetivo:** Pesquisar concorrentes, validar viabilidade técnica.
**Entrega:** Análise de 3 soluções similares + diferencial do projeto.

### AULAS 05-06 — Requisitos e User Stories
**Objetivo:** Documentar requisitos funcionais e não-funcionais.
**Entrega:** Backlog com 15+ user stories priorizadas (MoSCoW).

### AULAS 07-08 — Arquitetura e Stack Tecnológica
**Objetivo:** Definir arquitetura (front, back, banco, mobile, infra).
**Entrega:** Diagrama de arquitetura + justificativa da stack.

### AULAS 09-10 — Setup do Projeto e Git Flow
**Objetivo:** Criar repositório, configurar CI, Docker, README.
**Entrega:** Repo no GitHub com estrutura base + pipeline CI verde.

---

## FASE 2: DESENVOLVIMENTO - Sprint 1 (Aulas 11-20)

### AULAS 11-12 — Sprint Planning 1
**Objetivo:** Selecionar user stories para Sprint 1 (2 semanas).
**Entrega:** Sprint backlog no GitHub Projects.

### AULAS 13-14 — Desenvolvimento: Auth + Modelo de Dados
**Objetivo:** Implementar login/cadastro + criar banco.
**Acompanhamento:** Daily standup de 5 min no início da aula.

### AULAS 15-16 — Desenvolvimento: CRUD Principal
**Objetivo:** Funcionalidade core do sistema funcionando.

### AULAS 17-18 — Desenvolvimento: Integração Front ↔ Back
**Objetivo:** Front-end consumindo a API.

### AULAS 19-20 — Sprint Review 1 + Retrospectiva
**Formato:** Demo de 10 min por equipe + feedback do professor.

---

## FASE 3: DESENVOLVIMENTO - Sprint 2 (Aulas 21-30)

### AULAS 21-22 — Sprint Planning 2
### AULAS 23-24 — Desenvolvimento: Features Secundárias
### AULAS 25-26 — Desenvolvimento: Mobile ou Recursos Nativos
### AULAS 27-28 — Desenvolvimento: Testes + Segurança
### AULAS 29-30 — Sprint Review 2 + Retrospectiva

---

## FASE 4: FINALIZAÇÃO (Aulas 31-40)

### AULAS 31-32 — Sprint 3: Bug Fixes e Polish
**Objetivo:** Corrigir bugs, melhorar UX, otimizar performance.

### AULAS 33-34 — Deploy e Documentação
**Objetivo:** Deploy funcional + README completo + Swagger + vídeo demo.

### AULAS 35-36 — Preparação da Apresentação
**Objetivo:** Montar slides, ensaiar demo ao vivo, preparar para perguntas.

### AULAS 37-38 — Apresentação Final (Parte 1)
**Formato:** 20 min por equipe: pitch + demo + perguntas da banca.

### AULAS 39-40 — Apresentação Final (Parte 2) + Encerramento
**Formato:** Restante das equipes + feedback final + certificados.

---

## 🏆 Rubrica de Avaliação do TCC

| Critério | Peso | Descrição |
|---|---|---|
| Funcionalidade | 25% | App funciona end-to-end |
| Código e Arquitetura | 20% | Organização, padrões, camadas |
| Infraestrutura (Docker/CI) | 15% | Deploy, pipeline, containers |
| Testes e Qualidade | 15% | Cobertura, testes passando |
| Apresentação | 15% | Clareza, demo, domínio técnico |
| Documentação | 10% | README, diagrama, instruções |
