## Capítulo 1 — Resumo Teórico Essencial

### 1.1 Autoconhecimento

Antes de planejar a carreira, é preciso conhecer a si mesmo. Três ferramentas poderosas:

#### SWOT Pessoal

Análise dos seus pontos fortes, fracos, oportunidades e ameaças:

| Interno | |
|---|---|
| **Strengths (Forças)** | O que faço bem? Que habilidades tenho? |
| **Weaknesses (Fraquezas)** | Onde preciso melhorar? O que evito? |

| Externo | |
|---|---|
| **Opportunities (Oportunidades)** | Que tendências me favorecem? Que recursos posso acessar? |
| **Threats (Ameaças)** | Que obstáculos enfrento? Que riscos existem? |

#### Ikigai

Conceito japonês para encontrar seu propósito — a interseção de 4 elementos:
1. O que você **ama** fazer
2. O que você **faz bem** (habilidade)
3. O que o mundo **precisa**
4. O que você pode ser **pago** para fazer

A interseção dos 4 = seu **Ikigai** (razão de viver/trabalhar)

#### Valores Pessoais

Seus valores guiam todas as decisões. Exemplos:
- Autonomia, Criatividade, Segurança financeira
- Aprendizado contínuo, Impacto social, Trabalho em equipe
- Equilíbrio vida/trabalho, Reconhecimento, Liberdade geográfica

### 1.3 Metas SMART

Uma meta bem definida segue 5 critérios:

| Letra | Critério | Pergunta |
|---|---|---|
| **S** | Specific (Específica) | O quê exatamente? |
| **M** | Measurable (Mensurável) | Como vou medir o progresso? |
| **A** | Achievable (Alcançável) | É possível com meus recursos? |
| **R** | Relevant (Relevante) | Faz sentido para meu objetivo maior? |
| **T** | Time-bound (Temporal) | Até quando? |

**Exemplo ruim:** "Quero aprender programação"
**Exemplo SMART:** "Vou completar o curso de Kotlin no Coursera (16h) até 30/março, estudando 1h por dia de segunda a sexta, para conseguir meu primeiro estágio em mobile."

### 1.4 Gestão de Tempo

#### Técnica Pomodoro
1. Escolha uma tarefa
2. Configure timer: **25 minutos** (1 pomodoro)
3. Trabalhe com foco total (sem celular, sem redes sociais)
4. Pausa curta: **5 minutos**
5. A cada 4 pomodoros: pausa longa de **15-30 minutos**

#### Matriz de Eisenhower

| | Urgente | Não urgente |
|---|---|---|
| **Importante** | ✅ FAÇA AGORA (prova amanhã) | 📅 AGENDE (estudar para certificação) |
| **Não importante** | 👋 DELEGUE (email do grupo) | ❌ ELIMINE (scroll infinito nas redes) |

**Insight para estudante de TI:** O quadrante mais negligenciado é "Importante + Não Urgente" — é onde está estudar por conta, fazer projetos pessoais, networking. Quem só vive no "Urgente" está sempre apagando incêndio.

### 1.5 Soft Skills

Habilidades técnicas abrem portas, mas soft skills determinam até onde você sobe.

**Top 5 soft skills para TI:**
1. **Comunicação** — Explicar coisas técnicas para não-técnicos
2. **Trabalho em equipe** — Programar é coletivo (Git, code review, daily)
3. **Resolução de problemas** — A essência da programação
4. **Adaptabilidade** — Tecnologias mudam rápido
5. **Gestão de tempo** — Entregas com prazo, multiple tasks

**Networking — Por que importa:**
- 70% das vagas são preenchidas por indicação
- Comunidade: eventos, meetups, Discord, LinkedIn
- Mentor: alguém 2-3 anos à frente no caminho que você quer seguir

### 1.6 LinkedIn e Currículo para TI

**LinkedIn — O que um recrutador tech busca:**
- Headline objetiva: "Estudante de Desenvolvimento de Sistemas | Kotlin | Firebase"
- Sobre (Summary): 3-4 parágrafos com sua história, foco e objetivo
- Experiência: projetos pessoais/acadêmicos contam!
- Skills: adicione tecnologias específicas
- Projetos: links para GitHub, portfólio, deploy

**Currículo dev júnior — O que incluir:**
- Projetos práticos com link para código (GitHub)
- Tecnologias que você realmente usa
- Formação (curso técnico + cursos online relevantes)
- Objetivo claro e direto (1 linha)
- SEM: foto 3×4 antiga, "pacote Office", endereço completo

### 2.3 Script de Elevator Pitch (30 segundos)


**Estrutura do Elevator Pitch:**

```
FÓRMULA: [Quem sou] + [O que faço/estudo] + [Diferencial] + [Objetivo]
```

**Exemplo 1 — Para recrutador:**
> "Oi! Eu sou a Maria, estou no 2º ano do técnico em Desenvolvimento de Sistemas na ETE Pernambuco. Tenho me especializado em Android com Kotlin e Firebase — inclusive criei um app de controle financeiro que já tem 50 downloads na Play Store. Estou buscando uma oportunidade de estágio onde eu possa aprender com um time experiente e contribuir com projetos mobile."

**Exemplo 2 — Para evento de networking:**
> "Sou o Pedro, desenvolvedor mobile em formação. Curto muito resolver problemas com código — meu último projeto foi um app de delivery para o bairro usando Kotlin e Firebase. Estou buscando meu primeiro estágio e adoraria conhecer mais sobre como funciona o dia a dia de dev aqui na empresa de vocês."

**Dicas:**
- Pratique em voz alta (grave e ouça)
- 30 segundos = ~75-90 palavras
- Mantenha natural (não decorado como robô)
- Adapte para cada situação (recrutador ≠ dev ≠ evento)

### 2.5 Checklist LinkedIn Completo

**Configuração inicial:**
- [ ] Foto profissional (rosto visível, fundo neutro, sorriso natural)
- [ ] Banner personalizado (canva.com — template "LinkedIn Banner")
- [ ] Headline estratégica (não apenas "Estudante")

**Seção "Sobre" (About):**
- [ ] Parágrafo 1: Quem você é e o que faz
- [ ] Parágrafo 2: Suas habilidades e tecnologias
- [ ] Parágrafo 3: O que busca (estágio, oportunidades)
- [ ] Palavras-chave relevantes (Kotlin, Android, Firebase, etc.)

**Experiência:**
- [ ] Projetos pessoais listados como "Personal Project"

- [ ] Cursos online relevantes

## Capítulo 3 — Glossário Técnico

| Termo em Inglês | Significado em Português |
|---|---|
| **Soft Skills** | Habilidades comportamentais (comunicação, liderança, empatia) |
| **Hard Skills** | Habilidades técnicas mensuráveis (linguagens, ferramentas) |
| **Networking** | Construção e manutenção de rede de contatos profissionais |
| **Personal Branding** | Marca pessoal — como você é percebido profissionalmente |
| **Portfolio** | Portfólio — coleção de projetos que demonstra suas habilidades |
| **Resume/CV** | Currículo — documento resumo da sua trajetória profissional |
| **LinkedIn** | Rede social profissional para networking e vagas |
| **GitHub** | Plataforma para hospedar código e demonstrar projetos |
| **Freelance** | Trabalho autônomo por projeto (sem vínculo empregatício) |
| **CLT** | Carteira assinada — regime trabalhista brasileiro com benefícios |
| **PJ** | Pessoa Jurídica — contrato como prestador de serviço (CNPJ) |
| **Startup** | Empresa inovadora em fase inicial de crescimento acelerado |
| **Junior/Mid/Senior** | Níveis de experiência profissional (júnior → pleno → sênior) |
| **Full Stack** | Desenvolvedor que atua tanto no front-end quanto no back-end |
| **Front-end** | Parte visual/interface do sistema (o que o usuário vê) |
| **Back-end** | Parte do servidor/lógica do sistema (o que roda "por trás") |
| **DevOps** | Cultura/cargo que une desenvolvimento e operações/infraestrutura |
| **UX/UI** | Experiência do Usuário / Interface do Usuário (design) |
| **QA** | Quality Assurance — garantia de qualidade (testes de software) |
| **Data Science** | Ciência de Dados — extrair insights de grandes volumes de dados |
| **Agile** | Metodologias ágeis (Scrum, Kanban) para gestão de projetos |
| **Sprint** | Ciclo curto de trabalho (geralmente 2 semanas) no Scrum |
| **Stakeholder** | Parte interessada no projeto (cliente, gestor, usuário) |
| **Elevator Pitch** | Apresentação pessoal rápida (30-60 segundos) |
| **SMART** | Critérios para metas: Specific, Measurable, Achievable, Relevant, Time-bound |
