## 💻 Instalação do GIMP

### 🪟 Windows

1. Acesse: [https://www.gimp.org/downloads/](https://www.gimp.org/downloads/)
2. Clique em **"Download GIMP directly"** (versão Windows)
3. Execute o instalador `.exe` baixado
4. Siga o assistente de instalação (Next → Next → Install)
5. Aguarde a conclusão e clique em **Finish**
6. Abra o GIMP pelo Menu Iniciar

### 🍎 macOS

1. Acesse: [https://www.gimp.org/downloads/](https://www.gimp.org/downloads/)
2. Clique na versão para **macOS** (arquivo `.dmg`)
3. Abra o arquivo `.dmg` baixado
4. Arraste o ícone do GIMP para a pasta **Aplicativos**
5. Na primeira abertura: clique com botão direito → Abrir (para autorizar)
6. O GIMP estará disponível no Launchpad

> 💡 **Dica:** O GIMP é 100% gratuito e open source. Funciona como alternativa profissional ao Adobe Photoshop.

## 📚 Material Teórico

### 1. Comparação de Formatos de Imagem

| Formato | Tipo | Compressão | Transparência | Animação | Melhor uso |
|---------|------|-----------|---------------|----------|------------|
| **JPG** | Bitmap | Lossy | ❌ Não | ❌ Não | Fotografias, imagens com muitas cores |
| **PNG** | Bitmap | Lossless | ✅ Sim | ❌ Não | Logos, ícones, imagens com transparência |
| **GIF** | Bitmap | Lossless (até 256 cores) | ✅ Sim (1 bit) | ✅ Sim | Animações simples, memes |
| **WebP** | Bitmap | Lossy/Lossless | ✅ Sim | ✅ Sim | Web (substitui JPG/PNG com menor tamanho) |
| **SVG** | Vetor | N/A (XML) | ✅ Sim | ✅ Sim (CSS/JS) | Logos, ícones, ilustrações escaláveis |

### 2. RGB vs CMYK

```
┌─────────────────────────────────────────────────────────────────┐
│                    MODELOS DE COR                                │
├────────────────────────────┬────────────────────────────────────┤
│          RGB               │             CMYK                   │
├────────────────────────────┼────────────────────────────────────┤
│ Red + Green + Blue         │ Cyan + Magenta + Yellow + Key(Preto)│
│ Modelo ADITIVO (luz)       │ Modelo SUBTRATIVO (tinta)          │
│ Usado em: telas, monitores │ Usado em: impressão gráfica        │
│ Preto = ausência de luz    │ Preto = soma de todas as tintas    │
│ Branco = todas as cores    │ Branco = ausência de tinta         │
│ 16,7 milhões de cores      │ Gama de cores mais limitada        │
│ Ideal para: web, vídeo     │ Ideal para: folders, cartões       │
└────────────────────────────┴────────────────────────────────────┘
```

### 3. HSL (Matiz, Saturação, Luminosidade)

- **H (Hue/Matiz):** O "nome" da cor no círculo cromático (0°–360°)
- **S (Saturation/Saturação):** Intensidade da cor (0% = cinza, 100% = pura)
- **L (Lightness/Luminosidade):** Claro ou escuro (0% = preto, 100% = branco)

> 💡 HSL é intuitivo para ajustes: quer mais "vivo"? Aumente a saturação. Quer mais claro? Aumente a luminosidade.

### 4. Resolução e DPI

| Contexto | Resolução recomendada |
|----------|----------------------|
| Web / Tela | 72 DPI |
| Impressão caseira | 150 DPI |
| Impressão profissional | 300 DPI |
| Outdoor / Banner grande | 50–100 DPI |

> **DPI** = Dots Per Inch (Pontos por Polegada). Mais DPI = mais detalhes por polegada impressa.

### 6. Camadas — Analogia das Folhas Transparentes

```
    ┌─────────────────────┐  ← Camada 4: Texto ("Minha Marca")
    │   Minha Marca       │
    ├─────────────────────┤  ← Camada 3: Logo (PNG com transparência)
    │      🎯             │
    ├─────────────────────┤  ← Camada 2: Efeito (filtro de cor)
    │  ░░░░░░░░░░░░░░░░░  │
    ├─────────────────────┤  ← Camada 1: Foto de fundo
    │  🏔️ Paisagem        │
    └─────────────────────┘

    👁️ Cada camada é como uma folha de acetato transparente.
    Você empilha as folhas e o resultado final é a combinação
    de todas elas vistas de cima para baixo.
```

**Conceitos-chave:**
- Camadas superiores cobrem as inferiores
- Opacidade controla a "transparência" de cada folha
- Modos de mesclagem alteram como as cores interagem entre camadas
- Você pode editar cada camada independentemente

## ✏️ Exercícios Práticos

### Exercício 1 — Tratamento de Foto (Brilho e Contraste)

**Objetivo:** Aprender ajustes básicos de iluminação em uma fotografia.

**Instruções:**
1. Abra uma foto escura/subexposta no GIMP
2. Vá em `Cores → Brilho-Contraste`
3. Ajuste o brilho para clarear a imagem (+30 a +60)
4. Ajuste o contraste para dar mais definição (+20 a +40)
5. Use `Cores → Níveis` para ajuste fino (mova o ponto médio)
6. Use `Cores → Curvas` para realçar tons médios
7. Compare o antes/depois (use `Editar → Desfazer` para alternar)
8. Exporte como JPG com qualidade 85%

**Entrega:** Arquivo `.xcf` (editável) + `.jpg` (exportado)

---

### Exercício 2 — Criar Banner para YouTube

**Objetivo:** Criar um banner profissional para canal do YouTube.

**Especificações técnicas:**
- Dimensão: **2560 × 1440 px** (tamanho recomendado pelo YouTube)
- Área segura (visível em todos os dispositivos): **1546 × 423 px** (centro)
- Resolução: 72 DPI
- Formato de saída: PNG

**Instruções:**
1. `Arquivo → Novo` → 2560 × 1440 px
2. Crie uma camada de fundo com gradiente ou cor sólida
3. Adicione uma imagem/foto relacionada ao tema do canal
4. Insira o nome do canal usando ferramenta de Texto (fonte grande, legível)
5. Adicione um slogan ou descrição em fonte menor
6. Certifique-se de que informações importantes estejam na área segura central
7. Exporte como PNG

**Critérios de avaliação:**
- [ ] Dimensões corretas (2560 × 1440 px)
- [ ] Informações na área segura
- [ ] Hierarquia visual clara (título > subtítulo > detalhes)
- [ ] Boa legibilidade do texto
- [ ] Estética harmoniosa (cores, fontes, espaçamento)

---

### Exercício 3 — Remover Fundo de Imagem

**Objetivo:** Extrair um objeto/pessoa do fundo para uso em composições.

**Instruções:**
1. Abra uma foto com um objeto/pessoa em destaque
2. Adicione canal Alpha: `Camada → Transparência → Adicionar Canal Alfa`
3. **Método 1 — Seleção por Cor:**
   - Use `Selecionar por Cor` no fundo uniforme
   - Ajuste o limiar para pegar todas as variações
   - Pressione `Delete` para remover
4. **Método 2 — Caminhos (Paths):**
   - Use a ferramenta Caminhos para contornar o objeto
   - Converta o caminho em seleção
   - Inverta a seleção (`Selecionar → Inverter`)
   - Delete o fundo
5. Refine as bordas com `Selecionar → Enevoar` (1-2px)
6. Exporte como **PNG** (para manter a transparência)

**Entrega:** Arquivo `.xcf` + `.png` com fundo transparente

---

### Exercício 4 — Criar Post para Instagram

**Objetivo:** Criar uma arte para post de feed do Instagram.

**Especificações técnicas:**
- Dimensão: **1080 × 1080 px** (post quadrado)
- Resolução: 72 DPI
- Formato de saída: PNG ou JPG (qualidade 90%)

**Instruções:**
1. `Arquivo → Novo` → 1080 × 1080 px
2. Defina um tema (ex: dica de tecnologia, frase motivacional, promoção)
3. Crie um fundo atrativo (cor sólida, gradiente ou foto tratada)
4. Adicione texto principal (máximo 6–8 palavras em destaque)
5. Adicione texto secundário (informação complementar)
6. Inclua elementos gráficos (formas, linhas, ícones)
7. Mantenha margens de segurança (pelo menos 50px de cada lado)
8. Verifique contraste texto × fundo

**Critérios de avaliação:**
- [ ] Dimensões corretas (1080 × 1080 px)
- [ ] Texto legível mesmo em tela pequena
- [ ] Harmonia de cores (máximo 3 cores principais)
- [ ] Margens respeitadas
- [ ] Mensagem clara e objetiva
- [ ] Criatividade e originalidade

**Entrega:**
- Arquivo `.xcf` com todas as camadas organizadas e nomeadas
- Exportação `.jpg` — versão final (antes e depois lado a lado)
- Breve relatório (máx. 1 página) descrevendo os passos realizados

## 📝 Simulado e Prova

### Simulado — Questões Teóricas

**1.** Qual formato de imagem é mais adequado para uma fotografia colorida a ser exibida em um site?

a) SVG
b) GIF
c) JPG ✅
d) BMP

**2.** Qual a diferença entre compressão lossy e lossless?

> **Resposta esperada:** Compressão lossy (com perdas) descarta informações permanentemente para reduzir o tamanho do arquivo — a qualidade diminui a cada salvamento. Compressão lossless (sem perdas) reduz o tamanho sem perder nenhuma informação original — a imagem pode ser reconstituída perfeitamente.

**3.** Uma imagem será impressa em um cartão de visita profissional. Qual resolução (DPI) é recomendada?

a) 72 DPI
b) 150 DPI
c) 300 DPI ✅
d) 50 DPI

**4.** No modelo RGB, qual cor resulta da combinação de Red (255) + Green (255) + Blue (0)?

a) Laranja
b) Amarelo ✅
c) Branco
d) Magenta

**5.** Qual modelo de cor é utilizado em impressão gráfica profissional?

a) RGB
b) HSL
c) CMYK ✅
d) HEX

**6.** Qual formato de imagem suporta transparência E animação?

a) JPG
b) PNG
c) WebP ✅
d) BMP

**7.** No GIMP, o que é um Canal Alfa?

> **Resposta esperada:** O Canal Alfa controla a transparência de cada pixel em uma camada. Onde o canal alfa é branco, a camada é opaca; onde é preto, a camada é transparente. Sem canal alfa, a camada não pode ter áreas transparentes.

**8.** Explique a analogia das camadas como "folhas de acetato transparente."

> **Resposta esperada:** Cada camada funciona como uma folha de plástico transparente empilhada. Você pode desenhar em cada folha independentemente. Ao olhar de cima, vê a combinação de todas as folhas sobrepostas. Camadas superiores cobrem as inferiores, e a opacidade controla o quanto cada folha deixa ver a camada abaixo.

**9.** Qual a diferença entre as ferramentas Clone e Healing no GIMP?

> **Resposta esperada:** A ferramenta Clone copia pixels de uma área de referência para outra, sem alteração. A ferramenta Healing (Restauração) também copia pixels, mas mistura a textura da fonte com a iluminação e cor da área de destino, produzindo resultado mais natural para retoques de pele e correções.

**10.** Quais as dimensões recomendadas para um post de feed do Instagram?

a) 1920 × 1080 px
b) 800 × 600 px
c) 1080 × 1080 px ✅
d) 2560 × 1440 px

### Prova Prática — Descrever Passos para Obter Efeito

**Questão Prática 1:** Descreva o passo a passo no GIMP para remover o fundo de uma foto de produto e exportar com transparência.

> **Resposta esperada:**
> 1. Abrir a imagem no GIMP
> 2. Adicionar Canal Alfa (`Camada → Transparência → Adicionar Canal Alfa`)
> 3. Selecionar o fundo com Seleção por Cor ou Caminhos (Paths)
> 4. Se usou Paths: converter caminho em seleção
> 5. Se selecionou o produto: `Selecionar → Inverter` para selecionar o fundo
> 6. Pressionar Delete para remover o fundo (ficará xadrez = transparente)
> 7. Refinar bordas com `Selecionar → Enevoar` (1-2px)
> 8. Exportar como PNG (`Arquivo → Exportar Como → .png`)

**Questão Prática 2:** Descreva o passo a passo para criar um efeito de dupla exposição no GIMP.

> **Resposta esperada:**
> 1. Abrir a foto base (ex: retrato de pessoa em silhueta)
> 2. Abrir a segunda imagem como camada (`Arquivo → Abrir como Camadas`)
> 3. Posicionar e redimensionar a segunda imagem sobre o retrato
> 4. Alterar o modo de mesclagem da camada superior para "Clarear" ou "Tela"
> 5. Adicionar máscara de camada na imagem superior (preta = oculta tudo)
> 6. Pintar com branco na máscara para revelar a segunda imagem dentro do retrato
> 7. Ajustar opacidade para equilíbrio visual
> 8. Ajustar cores e contraste para harmonia
> 9. Achatar imagem e exportar

**Questão Prática 3:** Descreva como criar um banner para YouTube com texto legível sobre foto de fundo.

> **Resposta esperada:**
> 1. Criar novo arquivo 2560 × 1440 px
> 2. Importar foto como camada de fundo
> 3. Criar camada de sobreposição semi-transparente (retângulo preto com opacidade 40-60%) para melhorar legibilidade do texto
> 4. Adicionar texto do título com fonte grande e em negrito (cor branca ou clara)
> 5. Adicionar subtítulo em fonte menor abaixo
> 6. Verificar que textos estão dentro da área segura central (1546 × 423 px)
> 7. Adicionar logo ou elementos decorativos
> 8. Exportar como PNG

> 🎯 **Ideal quando:** Alunos possuem smartphone com acesso à internet (Wi-Fi da escola ou dados móveis)

#### Ferramentas Mobile Gratuitas

| Ferramenta | Plataforma | Uso na Disciplina |
|-----------|-----------|-------------------|
| **Snapseed** (Google) | Android/iOS | Edição profissional de fotos — ajustes, filtros, healing |
| **Canva Mobile** | Android/iOS | Composição visual, banners, posts com templates |
| **Remove.bg** | Navegador mobile | Remoção automática de fundo por IA |
| **Photopea** | Navegador mobile | Editor completo estilo Photoshop no navegador |

#### Atividades Adaptadas para Smartphone

| Semana/Bloco | Atividade Original (PC) | Adaptação Mobile |
|-------------|------------------------|-----------------|
| Bloco 2 | Ajustes de brilho/contraste no GIMP | Snapseed: usar Auto-ajuste, depois ajuste manual para comparar |
| Bloco 3 | Retoque e restauração | Snapseed: Healing tool em foto do celular |
| Bloco 4 | Remoção de fundo | Remove.bg no navegador + Canva para compor |
| Bloco 5 | Banner para YouTube | Canva mobile com template 2560×1440 |
| Bloco 5 | Post Instagram | Canva mobile com template 1080×1080 |

#### 📋 Roteiro do Professor — Opção A

```
ANTES DA AULA:
1. Verificar Wi-Fi da escola está funcionando
2. Preparar link encurtado (bit.ly) para Photopea ou atividade
3. Escrever passo a passo no quadro ou imprimir QR Code

DURANTE A AULA:
1. (5 min) Explicar a ferramenta do dia e distribuir roteiro
2. (10 min) Demonstrar usando projetor + seu celular (espelhar tela)
3. (25 min) Alunos executam a atividade no smartphone
4. (10 min) Compartilham resultado (AirDrop, WhatsApp grupo ou Drive)

AVALIAÇÃO:
• Captura de tela do resultado final
• Upload no Google Classroom ou envio por WhatsApp/email
```

#### 📱 Guia do Aluno — Opção A

```
MATERIAIS NECESSÁRIOS:
✅ Smartphone carregado (mínimo 40% de bateria)
✅ App instalado: Snapseed OU Canva (baixar antes via Wi-Fi)
✅ Foto para editar (tirar antes da aula ou usar banco gratuito)

PASSO A PASSO SNAPSEED:
1. Abrir Snapseed → Tocar no "+" → Selecionar foto
2. Menu "Ferramentas" → escolher ajuste (Brilho, Contraste, etc.)
3. Deslizar dedo horizontalmente para ajustar intensidade
4. Confirmar com "✓" → Exportar → Salvar cópia

ENTREGA:
• Screenshot do antes/depois
• Enviar para professora via [canal definido]
```

### 🅱️ Opção B: Atividades Desplugadas (Unplugged)

> 🎯 **Ideal quando:** Não há internet disponível OU alunos não têm smartphone

#### Atividade B1: "Composição com Recortes"

| Item | Descrição |
|------|-----------|
| **Tema** | Princípios de composição visual |
| **Duração** | 40 minutos |
| **Materiais** | Revistas antigas, tesoura, cola, folha A4, régua |
| **Objetivo** | Aplicar regra dos terços, equilíbrio visual e hierarquia |

**📋 Roteiro do Professor:**
1. (10 min) Explicar no quadro: regra dos terços, ponto focal, equilíbrio simétrico vs assimétrico
2. (5 min) Mostrar exemplos impressos de composições boas e ruins
3. (20 min) Alunos recortam elementos de revistas e montam composição em folha A4 dividida em grid 3×3
4. (5 min) Cada aluno apresenta brevemente sua composição justificando escolhas

**📱 Guia do Aluno:**
- Divida a folha A4 em grid 3×3 (linhas leves a lápis)
- Recorte 3-5 elementos de revistas (imagens, textos, cores)
- Posicione o elemento principal em uma intersecção do grid (ponto de ouro)
- Cole criando hierarquia visual: maior = mais importante
- Entregue com nome e breve justificativa escrita no verso

#### Atividade B2: "Storyboard de Tratamento"

| Item | Descrição |
|------|-----------|
| **Tema** | Planejamento de edição de imagem |
| **Duração** | 40 minutos |
| **Materiais** | Folha A4, lápis, borracha, canetas coloridas |
| **Objetivo** | Planejar o processo de edição antes de executar no software |

**📋 Roteiro do Professor:**
1. (10 min) Explicar conceito de storyboard de edição: desenhar o antes/depois planejando cada etapa
2. (5 min) Distribuir ficha com template de 4 quadros
3. (20 min) Alunos desenham: Quadro 1 = imagem original, Quadro 2 = crop/enquadramento, Quadro 3 = ajustes de cor/luz, Quadro 4 = resultado final esperado
4. (5 min) Discussão em duplas: um aluno explica seu plano ao colega

**📱 Guia do Aluno:**
- Pense em uma foto que você gostaria de editar (pode ser imaginária)
- Quadro 1: Desenhe a foto original com os "problemas" (escura, torta, fundo poluído)
- Quadro 2: Desenhe o crop ideal — o que cortar fora?
- Quadro 3: Indique com setas e legendas: "+brilho", "saturação↑", "remover mancha"
- Quadro 4: Desenhe o resultado final esperado
- Anote abaixo quais ferramentas do GIMP usaria em cada etapa

---

#### Atividade B3: "Análise de Imagens Impressas"

| Item | Descrição |
|------|-----------|
| **Tema** | Análise crítica de composição e tratamento fotográfico |
| **Duração** | 40 minutos |
| **Materiais** | 5-10 fotos impressas (revista, jornal), checklist impresso |
| **Objetivo** | Identificar regra dos terços, ponto focal, balanço de branco, contraste |

**📋 Roteiro do Professor:**
1. (5 min) Revisar conceitos: regra dos terços, ponto focal, temperatura de cor
2. (5 min) Distribuir fotos impressas (1 por dupla) + checklist de análise
3. (20 min) Duplas analisam a foto preenchendo o checklist
4. (10 min) Rodízio: cada dupla recebe nova foto e repete. Discussão final coletiva.

**📱 Guia do Aluno — Checklist de Análise:**
- [ ] A foto segue a regra dos terços? Onde está o ponto focal?
- [ ] O horizonte está nivelado?
- [ ] As cores parecem naturais ou há dominância (amarelada/azulada)?
- [ ] Há bom contraste entre claro e escuro?
- [ ] O fundo compete com o assunto principal?
- [ ] Que edição você faria para melhorar esta foto? (descreva)

---

#### Atividade B4: "Briefing de Projeto Visual"

| Item | Descrição |
|------|-----------|
| **Tema** | Documentação profissional para edição de assets |
| **Duração** | 40 minutos |
| **Materiais** | Folha A4, caneta, modelo de briefing impresso |
| **Objetivo** | Criar documento de especificação para edição de imagens do app |

**📋 Roteiro do Professor:**
1. (10 min) Explicar o que é um briefing visual profissional e sua importância
2. (5 min) Distribuir modelo de briefing
3. (20 min) Alunos preenchem briefing para as imagens do app AgendaPro (ou projeto da turma)
4. (5 min) Troca entre colegas: um avalia se o briefing do outro está claro o suficiente

**📱 Guia do Aluno — Modelo de Briefing:**
- **Peça:** (ex: banner do app, ícone, foto de perfil placeholder)
- **Dimensão final:** (ex: 1080×1080px)
- **Formato:** (PNG com transparência / JPG qualidade 85%)
- **Paleta de cores:** (listar HEX ou nome das cores)
- **Estilo:** (minimalista / fotográfico / ilustrado)
- **Referências:** (descrever ou colar print de referência)
- **Prazo:** (data de entrega)
- **Observações:** (restrições, elementos obrigatórios)

### 🅲 Opção C: Estudo de Caso / PBL (Problem-Based Learning)

> 🎯 **Ideal quando:** Aula geminada (2 horários seguidos) para debate aprofundado

#### Caso 1: "Como a Apple fotografa produtos para o site"

| Item | Descrição |
|------|-----------|
| **Foco** | Direção de arte e tratamento de imagem de produto |
| **Formato** | Análise + debate + proposta (40-50 min) |
| **Conexão** | Bloco 3-4 (tratamento fotográfico e composição) |

**Dinâmica:**
1. Professor apresenta 5-6 imagens de produtos Apple (iPhone, MacBook) do site oficial
2. Perguntas orientadoras: "Quantas fotos foram combinadas?", "Como eliminaram reflexos?", "Por que o fundo é sempre branco/preto?"
3. Alunos pesquisam (se houver internet) ou discutem em grupos de 4
4. Cada grupo apresenta: 3 técnicas identificadas + como fariam no GIMP

---

#### Caso 2: "Fake News e Manipulação de Imagens"

| Item | Descrição |
|------|-----------|
| **Foco** | Ética na edição de imagens |
| **Formato** | Tribunal simulado (40-50 min) |
| **Conexão** | Responsabilidade do editor / manipulação digital |

**Dinâmica:**
1. Professor mostra 4 imagens: 2 reais e 2 manipuladas (deepfake, retouch excessivo, contexto alterado)
2. Turma vota: qual é real, qual é fake?
3. Revelar respostas e discutir: "Quando a edição cruza a linha da ética?"
4. Debate estruturado: "Retocar pele em publicidade deveria ser proibido?" (metade defende SIM, metade NÃO)

---

#### Caso 3: "Otimização de Imagens para Performance Web"

| Item | Descrição |
|------|-----------|
| **Foco** | Compressão, formatos modernos e impacto no carregamento |
| **Formato** | Análise técnica + cálculos (40 min) |
| **Conexão** | Bloco 1 (formatos) e Bloco 5 (web) |

**Dinâmica:**
1. Dados: "Uma página com 20 imagens JPG de 2MB cada = 40MB para carregar"
2. Desafio: "Reduza o peso total para menos de 5MB sem perder qualidade visível"
3. Grupos calculam: qual formato usar (WebP?), qual compressão, lazy loading?
4. Apresentam solução com justificativa técnica

### 📊 Rubrica de Avaliação Adaptada (Atividades sem Laboratório)

| Critério | Excelente (10-9) | Bom (8-7) | Regular (6-5) | Insuficiente (<5) |
|----------|-----------------|-----------|---------------|-------------------|
| **Compreensão conceitual** | Demonstra domínio total dos conceitos de edição | Boa compreensão com pequenas lacunas | Compreensão básica, respostas superficiais | Não demonstra compreensão |
| **Aplicação prática** | Aplica corretamente em contexto novo | Aplica com pequenos erros | Aplica parcialmente | Não consegue aplicar |
| **Criatividade/Solução** | Solução original e bem fundamentada | Solução boa e funcional | Solução básica/genérica | Não apresenta solução |
| **Colaboração/Participação** | Participa ativamente, contribui com o grupo | Participa bem | Participação mínima | Não participa |
| **Entrega/Documentação** | Completa, organizada, dentro do prazo | Completa com pequenos ajustes | Incompleta mas entregue | Não entregou |

> 💡 **Nota:** Atividades de contingência têm o **mesmo peso** das atividades regulares. Qualidade de raciocínio é avaliada, não acesso a software.
