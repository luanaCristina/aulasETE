🎨 Fundamentos de Composição Visual

📐 Regra dos Terços

Divida a imagem em 9 quadrantes iguais. Posicione elementos importantes nas intersecções das linhas.

  • Guia o olhar do observador
  • Cria dinamismo (evita centralizar tudo)
  • Funciona em fotos, UI e banners

🎨 Teoria das Cores

  • RGB: Telas (luz aditiva)
  • CMYK: Impressão (tinta subtrativa)
  • HSL: Mais intuitivo para ajustes
  • Complementares: Contraste alto
  • Análogas: Harmonia suave

📏 Hierarquia Visual

  • Tamanho: Maior = mais importante
  • Contraste: Destaca do fundo
  • Espaçamento: Agrupa relacionados
  • Cor: Chama atenção para CTAs
  • Tipografia: Peso define importância
💡 Conexão com código: Estes princípios guiam suas escolhas de CSS — padding, font-size, color, layout!

🛠️ Ferramentas de Edição

🐧 GIMP (Desktop — Gratuito)

  • O que é: Editor profissional open source
  • Forte em: Tratamento de fotos, composição, pintura digital
  • Extensões: Scripts Python/Script-Fu
  • Formatos: PSD, PNG, JPEG, TIFF, XCF
  • Desvantagem: Interface menos intuitiva

🔗 gimp.org — Windows, Mac, Linux

🌐 Photopea (Web — Gratuito)

  • O que é: Photoshop online (sem instalar)
  • Forte em: Edição rápida, compatibilidade PSD
  • Vantagem: Funciona no navegador (Chromebook!)
  • Formatos: PSD, XD, Sketch, SVG, PNG
  • Desvantagem: Precisa de internet

🔗 photopea.com — Qualquer navegador

🎯 Na aula: Usaremos ambos — GIMP para projetos complexos e Photopea como plano B (funciona sem instalar).

📸 Tratamento Fotográfico

Fluxo de Edição (Passo a Passo)

  1. Crop: Enquadramento (regra dos terços)
  2. Níveis/Curvas: Ajuste de exposição
  3. Balanço de Branco: Temperatura da cor
  4. Saturação: Vibração das cores
  5. Nitidez: Unsharp Mask (com moderação)
  6. Remoção de imperfeições: Clone/Heal
  7. Exportação: Formato e tamanho adequados

📏 Formatos e Uso

FormatoUso idealCompressão
JPEGFotos (web/redes)Com perda (70-85%)
PNGÍcones, logos, transparênciaSem perda
WebPWeb moderna (menor tamanho)Com/sem perda
SVGÍcones vetoriais, logosVetorial (escala ∞)
AVIFNext-gen web (melhor compressão)Com perda
⚠️ Regra: Fotos = JPEG/WebP | Transparência = PNG | Ícones = SVG
