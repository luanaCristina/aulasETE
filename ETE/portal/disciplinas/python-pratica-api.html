🚦 Condicionais escolhem um caminho

JavaScript

JavaScriptif (media >= 7) { situacao = 'aprovado'; } else if (media >= 5) { situacao = 'recuperação'; } else { situacao = 'reprovado'; }

🧩 Funções recebem, processam e devolvem

Python com tipos

Pythondef calcular_media(notas: list[float]) -> float: if not notas: return 0.0 return sum(notas) / len(notas) media = calcular_media([8.0, 9.0, 7.0])

Correspondência em JS

JavaScriptfunction calcularMedia(notas) { if (notas.length === 0) return 0; return notas.reduce((soma, n) => soma + n, 0) / notas.length; }

Prefira return a apenas print: assim a função pode ser reutilizada e testada.

🧪 Erros são sinais para tratar, não esconder

Trate um erro esperado

Pythontry: idade = int(input('Idade: ')) except ValueError: print('Digite um número inteiro.') else: print(f'Idade registrada: {idade}')

Teste simples

Pythondef eh_aprovado(media: float) -> bool: return media >= 7 assert eh_aprovado(7.0) is True assert eh_aprovado(6.9) is False

Um teste descreve o comportamento esperado antes que alguém use a função de forma errada.

📨 Flask lê JSON, valida e retorna status

app.pyfrom flask import request tarefas = [] @app.post('/tarefas') def criar_tarefa(): dados = request.get_json(silent=True) or {} titulo = str(dados.get('titulo', '')).strip() if len(titulo) < 3: return jsonify(error='TITLE_INVALID'), 400 tarefa = {'id': len(tarefas) + 1, 'titulo': titulo, 'concluida': False} tarefas.append(tarefa) return jsonify(tarefa), 201

No Postman/Bruno, envie Content-Type: application/json e body {"titulo":"Estudar Python"}.

📝 Exercício 1 — Média e situação

Faça um programa que

  1. Leia três notas com input().
  2. Crie uma função calcular_media.
  3. Informe aprovado, recuperação ou reprovado.
  4. Trate texto inválido sem encerrar o programa.

Teste obrigatório

Execute ao menos três cenários:

  • 8, 7, 9 → aprovado;
  • 5, 5, 6 → recuperação;
  • 3, 4, 4 → reprovado.

✅ Gabarito 1 — Boletim com funções

Pythondef calcular_media(notas): return sum(notas) / len(notas) try: notas = [float(input(f'Nota {n}: ')) for n in range(1, 4)] media = calcular_media(notas) if media >= 7: situacao = 'aprovado' elif media >= 5: situacao = 'recuperação' else: situacao = 'reprovado' print(f'Média: {media:.1f} — {situacao}') except ValueError: print('Digite apenas números nas notas.')

✅ Gabarito 2 — PATCH com validação de id

Python@app.patch('/tarefas/<int:tarefa_id>') def concluir_tarefa(tarefa_id): tarefa = next((t for t in tarefas if t['id'] == tarefa_id), None) if not tarefa: return jsonify(error='TASK_NOT_FOUND'), 404 tarefa['concluida'] = True return jsonify(tarefa), 200 @app.delete('/tarefas/<int:tarefa_id>') def remover_tarefa(tarefa_id): tarefa = next((t for t in tarefas if t['id'] == tarefa_id), None) if not tarefa: return jsonify(error='TASK_NOT_FOUND'), 404 tarefas.remove(tarefa) return '', 204
