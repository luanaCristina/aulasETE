📚 Conceitos Fundamentais

🤔 O que é um Banco de Dados?

Uma coleção organizada de dados que permite busca, inserção e atualização de forma eficiente.

💡 Analogia: Planilha Excel = arquivo solto na gaveta. Banco de Dados = biblioteca com catálogo, índice e bibliotecária.

📊 SGBD (Sistema Gerenciador)

  • PostgreSQL — robusto, grátis, padrão do mercado
  • MySQL — popular em web (WordPress)
  • SQLite — embutido (mobile/desktop)
  • SQL Server — corporativo (Microsoft)

⚠️ Banco de Dados ≠ Excel. BD garante: integridade, concorrência, backup, segurança.

📐 Modelagem: Diagrama Entidade-Relacionamento

O DER é o mapa do banco — mostra entidades, atributos e como se conectam.

🧩 Componentes do DER

  • Entidade — retângulo (Ex: Cliente, Produto, Pedido)
  • Atributo — elipse (Ex: nome, cpf, preço)
  • Relacionamento — losango (Ex: "realiza", "contém")
  • Cardinalidade — quantos de cada lado

📊 Cardinalidades

1:1Pessoa ↔ CPF
1:NCliente ↔ Pedidos
N:MAluno ↔ Disciplinas

📝 Exemplo: Pet Shop

🔧 Normalização: 1FN, 2FN, 3FN

Normalizar = eliminar redundâncias e garantir integridade dos dados.

🏗️ DDL — Linguagem de Definição de Dados

Comandos que criam e modificam a estrutura do banco.

SQL -- Criar tabela de clientes CREATE TABLE clientes ( id SERIAL PRIMARY KEY, nome VARCHAR(100) NOT NULL, email VARCHAR(150) UNIQUE NOT NULL, telefone VARCHAR(20), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); -- Criar tabela de pets (FK para clientes) CREATE TABLE pets ( id SERIAL PRIMARY KEY, nome VARCHAR(80) NOT NULL, especie VARCHAR(30) NOT NULL CHECK (especie IN ('cão','gato','ave','outro')), raca VARCHAR(50), cliente_id INTEGER NOT NULL REFERENCES clientes(id) ON DELETE CASCADE ); -- Alterar tabela: adicionar coluna ALTER TABLE clientes ADD COLUMN cpf VARCHAR(14) UNIQUE; -- Remover tabela (CUIDADO!) DROP TABLE IF EXISTS pets;
⚠️ DROP é irreversível! Sempre use IF EXISTS e faça backup antes.

📝 DML — Manipulação de Dados (CRUD)

Comandos do dia a dia: inserir, buscar, atualizar, deletar.

SQL -- INSERT: cadastrar cliente INSERT INTO clientes (nome, email, telefone) VALUES ('Maria Silva', 'maria@email.com', '(81) 99999-1234'); -- SELECT: buscar clientes de Recife SELECT id, nome, email FROM clientes WHERE telefone LIKE '(81)%' ORDER BY nome; -- SELECT com JOIN: pets com seus donos SELECT p.nome AS pet, p.especie, c.nome AS dono FROM pets p INNER JOIN clientes c ON c.id = p.cliente_id; -- UPDATE: atualizar telefone UPDATE clientes SET telefone = '(81) 98888-5678' WHERE email = 'maria@email.com'; -- DELETE: remover cliente (cascade remove pets) DELETE FROM clientes WHERE id = 5;
💡 CRUD: Create (INSERT) | Read (SELECT) | Update (UPDATE) | Delete (DELETE)

📖 Referência de Comandos — DDL (Estrutura)

Comandos que alteram a estrutura do banco (tabelas, colunas, índices):

MySQL 
-- ═══ CREATE ═══ (Criar)
CREATE DATABASE minha_loja;          -- Criar banco
CREATE TABLE categoria (             -- Criar tabela
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(50) NOT NULL,
  descricao TEXT
);
CREATE INDEX idx_nome ON categoria(nome);  -- Criar índice

-- ═══ ALTER ═══ (Alterar estrutura)
ALTER TABLE categoria ADD COLUMN ativa BOOLEAN DEFAULT TRUE;
ALTER TABLE categoria MODIFY COLUMN nome VARCHAR(100);
ALTER TABLE categoria RENAME COLUMN descricao TO detalhes;
ALTER TABLE categoria RENAME TO categorias;

-- ═══ DROP ═══ (Destruir)
DROP INDEX idx_nome ON categorias;    -- Remove índice
DROP TABLE categorias;               -- Remove tabela inteira
DROP DATABASE minha_loja;            -- Remove banco inteiro

-- ═══ TRUNCATE ═══ (Limpar dados, manter estrutura)
TRUNCATE TABLE consulta;  -- Apaga TODOS os dados (mais rápido que DELETE)

📖 Referência de Comandos — DML (Dados)

Comandos que manipulam os dados dentro das tabelas:

MySQL 
-- ═══ INSERT ═══ (Inserir)
INSERT INTO cliente (nome, telefone) VALUES ('Paula', '81900001111');
INSERT INTO cliente (nome, telefone) VALUES 
  ('Rafa', '81900002222'),
  ('Leo', '81900003333');  -- Múltiplos de uma vez

-- ═══ SELECT ═══ (Consultar)
SELECT * FROM cliente;                    -- Todos os campos
SELECT nome, email FROM cliente;          -- Campos específicos

SELECT * FROM cliente ORDER BY nome ASC;  -- Ordenação
SELECT * FROM cliente LIMIT 3;            -- Limitar resultados
SELECT DISTINCT especie FROM pet;         -- Valores únicos
SELECT COUNT(*) FROM pet;                 -- Contar registros
SELECT especie, COUNT(*) AS qtd FROM pet GROUP BY especie;  -- Agrupar
SELECT especie, COUNT(*) AS qtd FROM pet 
  GROUP BY especie HAVING qtd > 1;        -- Filtro após GROUP BY

-- ═══ UPDATE ═══ (Atualizar)
UPDATE cliente SET email = 'novo@email.com' WHERE id = 2;
UPDATE pet SET especie = 'Canino' WHERE especie = 'Cachorro';  -- Em massa

-- ═══ DELETE ═══ (Excluir)
DELETE FROM consulta WHERE id = 3;
DELETE FROM pet WHERE especie = 'Canino' AND raca = 'Poodle';

📖 Referência de Comandos — JOIN e Subconsultas

Combinando dados de múltiplas tabelas:

MySQL 
-- ═══ INNER JOIN ═══ (só retorna onde há correspondência nas duas tabelas)
SELECT c.nome AS cliente, p.nome AS pet
FROM cliente c
INNER JOIN pet p ON c.id = p.cliente_id;

-- ═══ LEFT JOIN ═══ (retorna todos da esquerda, mesmo sem correspondência)
SELECT c.nome, p.nome AS pet
FROM cliente c
LEFT JOIN pet p ON c.id = p.cliente_id;
-- Clientes sem pet aparecem com NULL no campo 'pet'

-- ═══ RIGHT JOIN ═══ (retorna todos da direita)
SELECT c.nome, p.nome AS pet
FROM cliente c
RIGHT JOIN pet p ON c.id = p.cliente_id;

-- ═══ Subconsulta (SELECT dentro de SELECT) ═══
-- Clientes que têm pelo menos uma consulta:
SELECT nome FROM cliente 
WHERE id IN (SELECT DISTINCT cliente_id FROM consulta);

-- Pet mais recente consultado:
SELECT p.nome FROM pet p
WHERE p.id = (SELECT pet_id FROM consulta ORDER BY data DESC LIMIT 1);

-- ═══ ALIAS (apelidos) ═══
SELECT c.nome AS "Nome do Cliente", p.nome AS "Nome do Pet"
FROM cliente c
INNER JOIN pet p ON c.id = p.cliente_id;

📖 Comandos Extras Úteis

Outros comandos importantes que não usamos ainda:

MySQL 
-- ═══ SHOW ═══ (Ver estrutura)
SHOW DATABASES;               -- Lista todos os bancos
SHOW TABLES;                  -- Lista tabelas do banco atual
SHOW COLUMNS FROM cliente;    -- Mostra colunas de uma tabela
DESCRIBE cliente;             -- Igual ao SHOW COLUMNS (atalho)

-- ═══ USE ═══ (Selecionar banco)

-- ═══ LIKE ═══ (Busca parcial)
SELECT * FROM cliente WHERE nome LIKE 'Ma%';    -- Começa com "Ma"
SELECT * FROM cliente WHERE email LIKE '%@gmail%';  -- Contém "@gmail"
SELECT * FROM pet WHERE nome LIKE '___';        -- Exatamente 3 letras

-- ═══ BETWEEN ═══ (Intervalo)
SELECT * FROM consulta WHERE data BETWEEN '2026-08-01' AND '2026-08-15';
SELECT * FROM produto WHERE preco BETWEEN 20 AND 50;

-- ═══ IN ═══ (Lista de valores)
SELECT * FROM pet WHERE especie IN ('Cachorro', 'Gato', 'Pássaro');

-- ═══ IS NULL / IS NOT NULL ═══
SELECT * FROM cliente WHERE cpf IS NULL;
SELECT * FROM cliente WHERE email IS NOT NULL;

-- ═══ ORDER BY + LIMIT ═══ (Top N)
SELECT * FROM consulta ORDER BY data DESC LIMIT 3;  -- 3 mais recentes

-- ═══ UNION ═══ (Combinar resultados de 2 SELECTs)
SELECT nome, 'Cliente' AS tipo FROM cliente
UNION
SELECT nome, 'Veterinário' AS tipo FROM veterinario;

-- ═══ IF / CASE ═══ (Condicionais)
SELECT nome, 
  CASE 
    WHEN especie = 'Cachorro' THEN '🐕'
    WHEN especie = 'Gato' THEN '🐈'
    ELSE '🐾'
  END AS emoji
FROM pet;
