🐍 Python 3.12+ — Instalação

🪟 Windows

  1. Acesse python.org/downloads
  2. Baixe Python 3.12.x (64-bit)
  3. ⚠️ Marque "Add Python to PATH"
  4. Clique em "Install Now"
  5. Verifique no terminal:
CMD python --version # Python 3.12.x pip --version # pip 24.x

🍎 macOS

  1. Instale o Homebrew (se não tiver):
Terminal /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/ Homebrew/install/HEAD/install.sh)" brew install python@3.12 python3 --version # Python 3.12.x
💡 No macOS, use python3 e pip3 (não python).
⚠️ Pacotes essenciais: pip install psycopg2-binary python-dotenv

🐘 PostgreSQL 16 + pgAdmin 4

📥 Instalação (Windows + Mac)

  1. Acesse postgresql.org/download
  2. Baixe o instalador EDB (inclui pgAdmin)
  3. Durante a instalação:
    • Porta: 5432 (padrão)
    • Senha do superusuário: postgres
    • Marque pgAdmin 4 e Command Line Tools
  4. Finalize e reinicie se necessário

✅ Verificação

Terminal # Verificar versão psql --version # psql (PostgreSQL) 16.x # Conectar ao banco psql -U postgres # Digitar senha: postgres # Listar bancos \l # Sair \q
💡 pgAdmin 4: Interface gráfica para gerenciar o banco. Abra em localhost:5050 ou pelo atalho.

🐙 Git + GitHub

📥 Instalação do Git

Windows: git-scm.com (Git Bash incluído)

macOS: xcode-select --install ou brew install git

Terminal # Configuração inicial (OBRIGATÓRIA) git config --global user.name "Seu Nome" git config --global user.email "email@exemplo.com" git config --global init.defaultBranch main # Verificar git --version # git version 2.4x.x

🔑 GitHub — Configuração

  1. Crie conta em github.com
  2. Gere chave SSH:
Terminal ssh-keygen -t ed25519 -C "seu@email.com" # Enter para tudo (sem senha) cat ~/.ssh/id_ed25519.pub # Copie a chave inteira
  1. GitHub → Settings → SSH Keys → New
  2. Cole a chave e salve
  3. Teste: ssh -T git@github.com
