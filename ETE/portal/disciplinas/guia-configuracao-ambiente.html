✅ Checklist de preparação antes da aula

Confirmação no terminal

Terminalpython --version node --version npm --version git --version # quando for usar banco mysql --version psql --version

Confirmação na interface

  1. Abra VS Code e confira as extensões.
  2. Abra o cliente de banco da aula.
  3. Entre no GitHub ou GitHub Desktop.
  4. Abra Postman ou Bruno quando a atividade envolver APIs.
  5. Registre o que não funcionar antes da aula começar.
💡Uma ferramenta só está pronta depois de passar pela verificação. “Instalado” não é o mesmo que “funcionando”.
