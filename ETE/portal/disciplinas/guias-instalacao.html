🐍 Python 3.12+ — Instalação Completa

🪟 Windows

  1. Acesse python.org/downloads
  2. Baixe Python 3.12.x (64-bit)
  3. ⚠️ Marque "Add Python to PATH"
  4. Clique em "Install Now"
  5. Abra o CMD e verifique:
CMD python --version # Python 3.12.x pip --version # pip 24.x

🍎 macOS

  1. Instale o Homebrew (se não tiver):
Terminal /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/ Homebrew/install/HEAD/install.sh)" brew install python@3.12 python3 --version # Python 3.12.x
💡 No macOS use python3 e pip3.
⚠️ Pacotes essenciais: pip install psycopg2-binary python-dotenv flask pandas

🐘 PostgreSQL 16 + pgAdmin 4

📥 Instalação (Windows + Mac)

  1. Acesse postgresql.org/download
  2. Baixe o instalador EDB (inclui pgAdmin)
  3. Durante a instalação:
    • Porta: 5432 (padrão)
    • Senha superusuário: postgres
    • Marque pgAdmin 4 + Command Line Tools
  4. Finalize e reinicie se necessário
💡 macOS: brew install postgresql@16

✅ Verificação

Terminal psql --version # psql (PostgreSQL) 16.x psql -U postgres # Senha: postgres \l -- listar bancos \q -- sair # Criar banco de teste CREATE DATABASE escola;
📌 pgAdmin 4: Interface gráfica. Acesse pelo atalho ou localhost:5050.

📥 Instalação

  1. Acesse mongodb.com/try/download/community
  2. Baixe MongoDB Community Server 7.x
  3. Instale como serviço (padrão)
  4. Baixe MongoDB Compass (GUI)
Terminal # Verificar mongosh --version # Conectar mongosh # mongodb://localhost:27017 # macOS com Homebrew brew install mongodb-community@7.0 brew services start mongodb-community

🚀 Primeiro CRUD

mongosh // Criar banco use escola // Inserir documento db.alunos.insertOne({ nome: "Maria", turma: "DS-2026", notas: [8.5, 9.0, 7.5] }) // Buscar db.alunos.find({ turma: "DS-2026" }) // Atualizar db.alunos.updateOne( { nome: "Maria" }, { $push: { notas: 10.0 } } ) // Deletar db.alunos.deleteOne({ nome: "Maria" })

⚔️ SQL vs NoSQL — Quando Usar Cada?

CritérioSQL (PostgreSQL)NoSQL (MongoDB)
EstruturaTabelas com esquema fixoDocumentos JSON flexíveis
RelaçõesJOINs entre tabelasDados embarcados/referências
ConsultasSQL padrãoMétodos/agregações
EscalabilidadeVertical (servidor maior)Horizontal (mais servidores)
ACIDCompleto por padrãoPor documento (multi-doc opcional)
Ideal paraFinanças, ERP, relatóriosIoT, catálogos, tempo real
ExemploSistema de matrículasFeed de rede social
💡 Regra prática: Dados com muitas relações → SQL. Dados flexíveis e alta escala → NoSQL. Muitas empresas usam os DOIS juntos!

📊 Pentaho BI — Business Intelligence

📥 Download e Instalação

  1. Acesse sourceforge.net/projects/pentaho
  2. Baixe Pentaho Community Edition
  3. Extraia o ZIP (não instala, é portátil)
  4. Requer Java JDK 11+ instalado
  5. Execute: start-pentaho.bat (Win) ou ./start-pentaho.sh (Mac)
⚠️ Instale o Java JDK 11 antes: adoptium.net

🎯 Primeiro Dashboard

  1. Acesse localhost:8080/pentaho
  2. Login: admin / password
  3. File → New → CDE Dashboard
  4. Adicione fonte de dados (CSV ou SQL)
  5. Arraste componentes: gráficos, tabelas
  6. Publique e compartilhe
💡 Alternativa leve: Use o Metabase (mais moderno) via Docker.

🔧 Troubleshooting — Checklist Completo

🔍 Diagnóstico Rápido

  1. Terminal fechou e reabriu? (PATH atualiza)
  2. Está usando o terminal correto? (CMD/PowerShell/Bash)
  3. Versão correta? (--version)
  4. Permissão de admin? (Run as administrator)
  5. Firewall/antivírus bloqueando?
  6. Espaço em disco suficiente? (>5GB livre)
  7. Internet estável? (para npm/pip install)

🆘 Ordem de Socorro

  1. Google o erro exato (copie a mensagem)
  2. Stack Overflow — busque a pergunta
  3. Documentação oficial da ferramenta
  4. Pergunte à IA (Kiro, ChatGPT)
  5. Peça ajuda ao colega (pair debugging)
  6. Pergunte à professora — com print do erro!
💡 Dica: Sempre tire um print da tela do erro antes de pedir ajuda.

🐬 MySQL +
Workbench

Do instalador à primeira consulta SQL

Servidor guarda os dados. Workbench permite criar, consultar e administrar.

🪟 Windows — Instale Server e Workbench juntos

Passo a passo

  1. Acesse MySQL Installer e baixe a edição Community.
  2. Abra o instalador como usuário administrador e escolha Developer Default, ou selecione MySQL Server e MySQL Workbench.
  3. Na configuração, mantenha a porta 3306, defina e guarde a senha do usuário root.
  4. Conclua a configuração do serviço e abra o MySQL Workbench.
🔐Nunca compartilhe a senha do root nem a envie em trabalhos ou repositórios.

Imagem-guia: MySQL Installer

Procure os passos Type and Networking, Authentication Method e Accounts and Roles.

🍎 macOS — Server, Workbench e primeira abertura

Caminho visual (DMG)

  1. Baixe o MySQL Community Server para macOS e execute o instalador .dmg.
  2. Durante o assistente, memorize a senha do usuário root e confirme o servidor em execução.
  3. Baixe o MySQL Workbench, abra o DMG e arraste o app para Applications.
  4. Abra o Workbench pela pasta Applications e permita a abertura caso o macOS solicite confirmação.
Terminalmysql --version # Verifique se o cliente foi instalado mysql -u root -p # Digite a senha sem exibi-la na tela

Imagem-guia: Workbench no macOS

Ação principal: arraste o ícone do Workbench para Applications antes de abrir.

🔌 Workbench — Crie uma conexão local

Configure a conexão

CampoValor de aula
Connection NameMySQL local
Hostname127.0.0.1 ou localhost
Port3306
Usernameroot (somente no ambiente local)
PasswordClique em Store in Keychain/Vault apenas no computador pessoal

Clique em Test Connection. Só avance quando a mensagem de sucesso aparecer.

Se a conexão falhar

  1. Verifique se o MySQL Server está iniciado.
  2. Confira se a porta é 3306 e se ela não está ocupada por outro serviço.
  3. Revise usuário e senha; não tente instalar novamente antes de ler a mensagem de erro.
  4. No Windows, abra Services e procure MySQL80; no macOS, confira o painel MySQL em System Settings.
💡Servidor parado é diferente de senha errada. Leia a primeira linha útil do erro antes de agir.

🚀 Primeiros comandos no Workbench

Crie um banco da turma

SQLCREATE DATABASE IF NOT EXISTS escola_ete; USE escola_ete; CREATE TABLE IF NOT EXISTS alunos ( id INT AUTO_INCREMENT PRIMARY KEY, nome VARCHAR(100) NOT NULL, turma VARCHAR(20) NOT NULL, criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

Insira e consulte

SQLINSERT INTO alunos (nome, turma) VALUES ('Ana', 'DS 2026.2'); SELECT id, nome, turma, criado_em FROM alunos ORDER BY nome;

No Workbench, selecione o script e clique no ícone de raio. O painel inferior mostra o resultado e possíveis erros.

📌Exercício relâmpago: adicione a coluna email com ALTER TABLE, insira dois alunos e filtre apenas a turma DS 2026.2.
