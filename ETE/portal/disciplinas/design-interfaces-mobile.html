🎨 Material Design 3 — O Padrão do Android

Sistema de design do Google, base para apps Android modernos.

🧱 Pilares do MD3

  • Material You: Cores dinâmicas (wallpaper)
  • Tipografia: Escala tipográfica (5 níveis)
  • Elevation: Sombras e camadas
  • Motion: Transições significativas
  • Shape: Cantos arredondados (tokens)

🎨 Color Scheme

  • Primary: Ação principal (botões CTA)
  • Secondary: Ações secundárias
  • Tertiary: Acentos decorativos
  • Surface: Fundos de cards/modals
  • Error: Feedback de erro
  • On[Color]: Texto sobre cada cor
💡 Ferramenta: Use o Material Theme Builder (m3.material.io) para gerar paletas completas a partir de uma cor.

🧩 Componentes Nativos Android

Os building blocks essenciais de qualquer app mobile.

🔽 Bottom Navigation

  • 3-5 destinos principais
  • Ícone + label
  • Badge para notificações
  • Sempre visível no app

⊕ FAB (Floating Action Button)

  • Ação principal da tela
  • Canto inferior direito
  • Uma por tela (máximo)
  • Variantes: small, regular, large

🃏 Cards

  • Container de conteúdo
  • Elevated, Filled, Outlined
  • Ações no rodapé do card
  • Cantos arredondados (12dp)
🎯 No AgendaPro: Bottom Nav (Home, Buscar, Agenda, Perfil) + FAB (Novo Agendamento) + Cards (Médicos e Consultas)

🗺️ Padrões de Navegação Mobile

📱 Padrões Comuns

PadrãoQuando Usar
Tab Bar3-5 seções principais
Navigation Drawer6+ seções ou perfil complexo
Stack (push/pop)Fluxos lineares (lista → detalhe)
ModalAções rápidas, confirmações
Bottom SheetOpções contextuais

⚠️ Anti-padrões

  • ❌ Hamburger menu esconde funcionalidades
  • ❌ Mais de 5 tabs no bottom bar
  • ❌ Navegação profunda demais (4+ níveis)
  • ❌ Back button que não volta
  • ❌ Gestos sem alternativa visual
⚠️ Se o usuário se perde, a navegação falhou.

👆 Gestos e Animações

Interações táteis que tornam o app mais natural e intuitivo.

👆 Gestos Comuns

  • Tap: Ação principal (clique)
  • Long press: Menu contextual
  • Swipe horizontal: Deletar, arquivar
  • Swipe vertical: Scroll, pull-to-refresh
  • Pinch: Zoom (mapas, fotos)
  • Double tap: Curtir, zoom rápido

✨ Princípios de Animação

  • Duração: 200-300ms (transições)
  • Easing: ease-in-out (natural)
  • Hierarquia: Elementos maiores primeiro
  • Feedback: Confirmar ação do usuário
  • Continuidade: Manter contexto espacial

"Animação boa é aquela que ninguém percebe — mas sentiria falta."

♿ Acessibilidade Mobile

Design inclusivo não é opcional — é requisito profissional e legal.

✅ Checklist Essencial

  • Tamanho mínimo de toque: 48x48dp
  • Contraste de cores: 4.5:1 (texto normal)
  • Labels em todos os ícones (TalkBack)
  • Fonte escalável (respeitar configuração do sistema)
  • Navegação por foco (acessibilidade por teclado)
  • Não depender só de cor para informar

🛠️ Ferramentas de Teste

  • TalkBack: Leitor de tela Android
  • Accessibility Scanner: App do Google
  • Figma A11y plugins: Contrast checker
  • Stark: Plugin Figma para acessibilidade
💡 Ative o TalkBack e tente usar SEU app de olhos fechados.
