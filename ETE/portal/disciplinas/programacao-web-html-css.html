🏗️ HTML5 Semântico

Tags semânticas dão significado ao conteúdo — melhoram SEO, acessibilidade e manutenção.

❌ HTML genérico

HTML <div class="header"> <div class="nav">...</div> </div> <div class="main"> <div class="article">...</div> <div class="sidebar">...</div> </div> <div class="footer">...</div>

✅ HTML semântico

HTML <header> <nav>...</nav> </header> <main> <article>...</article> <aside>...</aside> </main> <footer>...</footer>
💡 Regra de ouro: Se existe uma tag HTML com o significado que você quer, use-a em vez de <div>.

📦 CSS3 — Box Model e Flexbox

Box Model

CSS /* Todo elemento é uma CAIXA */ .card { /* Conteúdo */ width: 300px; /* Espaço interno */ padding: 16px; /* Borda */ border: 1px solid #e5e7eb; /* Espaço externo */ margin: 12px; /* Truque: padding não soma na width */ box-sizing: border-box; }

Flexbox (1 direção)

CSS /* Container flex */ .navbar { display: flex; justify-content: space-between; align-items: center; gap: 16px; } /* Cards lado a lado */ .cards-container { display: flex; flex-wrap: wrap; gap: 24px; } .card { flex: 1 1 300px; /* cresce, encolhe, base */ }
⚠️ Sempre use box-sizing: border-box! Sem isso, padding e border somam na largura total.

📐 CSS Grid e Responsividade

CSS Grid (2 direções)

CSS /* Layout de dashboard */ .dashboard { display: grid; grid-template-columns: 250px 1fr; grid-template-rows: 60px 1fr; grid-template-areas: "sidebar header" "sidebar content"; min-height: 100vh; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .content { grid-area: content; }

📱 Mobile First

CSS /* Base: mobile (1 coluna) */ .grid-cards { display: grid; grid-template-columns: 1fr; gap: 16px; } /* Tablet: 2 colunas */ @media (min-width: 768px) { .grid-cards { grid-template-columns: repeat(2, 1fr); } } /* Desktop: 3 colunas */ @media (min-width: 1024px) { .grid-cards { grid-template-columns: repeat(3, 1fr); } }

O DOM (Document Object Model) é a representação da página HTML como objetos JavaScript.

Seleção de Elementos

Template Literals

🔌 Fetch API — Consumindo Dados

GET — Buscar dados

JavaScript // Buscar lista de produtos da API async function carregarProdutos() { try { const response = await fetch('/api/produtos'); if (!response.ok) throw new Error('Erro na API'); const produtos = await response.json(); renderizarLista(produtos); } catch (error) { exibirErro('Falha ao carregar produtos'); } } function renderizarLista(produtos) { const html = produtos.map(p => ` <div class="card">${p.nome} — R$${p.preco}</div> `).join(''); document.querySelector('#lista').innerHTML = html; }

POST — Enviar dados

JavaScript // Cadastrar novo produto async function cadastrarProduto(dados) { const response = await fetch('/api/produtos', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(dados) }); if (response.ok) { const novo = await response.json(); alert(`Produto ${novo.nome} criado!`); carregarProdutos(); // atualiza lista } } // Uso no formulário form.addEventListener('submit', (e) => { e.preventDefault(); cadastrarProduto({ nome, preco }); });
