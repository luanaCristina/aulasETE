Projeto guiado

Uma API de tarefas da turma: usuários se cadastram, fazem login, criam tarefas e consultam apenas seus próprios dados.

🧠Frontend mostra a interface; backend protege regras, dados e acessos.

🏗️ Backend é a parte que trabalha longe da tela

Responsabilidades

  • Receber uma requisição.
  • Validar dados e permissões.
  • Consultar ou alterar o banco.
  • Responder com status e JSON.

O que não deve fazer

  • Confiar em dados enviados pelo navegador.
  • Expor senha, token ou segredo.
  • Permitir que todo usuário acesse todos os dados.
  • Retornar um erro técnico sem explicação útil.

🚀 Express recebe e responde rotas

src/server.jsimport express from 'express'; const app = express(); app.use(express.json()); app.get('/health', (req, res) => { res.status(200).json({ ok: true }); }); const port = process.env.PORT || 3000; app.listen(port, () => console.log(`API em ${port}`));

A ordem importa: express.json() deve ser registrado antes das rotas que leem req.body.

🧰 Middleware prepara a rota

Header

Metadado da requisição: tipo de conteúdo, token, idioma, id de rastreio.

JavaScriptconst token = req.headers.authorization; const requestId = req.headers['x-request-id'];

Body JSON

JavaScriptapp.post('/tarefas', (req, res) => { const { titulo } = req.body; res.status(201).json({ titulo }); });

No Postman/Bruno: Header Content-Type: application/json + Body em JSON válido.

🛠️ Uma coleção REST tem rotas previsíveis

ObjetivoMétodo e rotaStatus típico

Use substantivos na URL, não verbos como /criarTarefa. O método HTTP já representa a ação.

🧪 Valide na fronteira da API

JavaScriptfunction validarTarefa(req, res, next) { const { titulo } = req.body; if (typeof titulo !== 'string' || titulo.trim().length < 3) { return res.status(400).json({ error: { code: 'TITLE_INVALID', message: 'Informe título com 3+ caracteres.' } }); } next(); } app.post('/tarefas', validarTarefa, criarTarefa);

O frontend ajuda a pessoa a preencher; o backend confirma que dados inválidos não entram no banco.

🐬 API usa conexão parametrizada com MySQL

Pool de conexões

JavaScriptimport mysql from 'mysql2/promise'; export const db = mysql.createPool({ host: process.env.DB_HOST, user: process.env.DB_USER, password: process.env.DB_PASSWORD, database: process.env.DB_NAME });

Consulta segura

JavaScriptconst [rows] = await db.execute( 'SELECT id, titulo, concluida FROM tarefas WHERE usuario_id = ?', [req.user.id] ); res.json({ data: rows });

Use placeholders ?. Nunca concatene dados da URL em SQL.

🔒 Senha nunca vai para o banco em texto puro

Cadastro seguro

Terminalnpm install bcrypt jsonwebtoken
JavaScriptimport bcrypt from 'bcrypt'; const senhaHash = await bcrypt.hash(senha, 12); await db.execute( 'INSERT INTO usuarios (nome, email, senha_hash) VALUES (?, ?, ?)', [nome, email, senhaHash] );

Login

JavaScriptconst valido = await bcrypt.compare( senha, usuario.senha_hash ); if (!valido) return res.sendStatus(401);

Hash é uma transformação de mão única. A API compara a senha recebida ao hash salvo sem precisar recuperar a senha original.

🪪 Token identifica o usuário em cada chamada

Gerar token no login

JavaScriptimport jwt from 'jsonwebtoken'; const token = jwt.sign( { sub: usuario.id }, process.env.JWT_SECRET, { expiresIn: '1h' } ); res.json({ token });

Proteger uma rota

JavaScriptfunction autenticar(req, res, next) { const [, token] = req.headers.authorization?.split(' ') ?? []; if (!token) return res.sendStatus(401); req.user = jwt.verify(token, process.env.JWT_SECRET); next(); } app.get('/tarefas', autenticar, listarTarefas);

👤 Login não basta: valide quem pode alterar

JavaScriptconst [rows] = await db.execute( 'SELECT id, usuario_id FROM tarefas WHERE id = ?', [req.params.id] ); const tarefa = rows[0]; if (!tarefa) return res.sendStatus(404); if (tarefa.usuario_id !== req.user.sub) return res.sendStatus(403); await db.execute( 'UPDATE tarefas SET concluida = ? WHERE id = ?', [true, tarefa.id] );
⚠️Um token válido prova quem chama; a autorização decide se essa pessoa pode alterar este recurso específico.

🌍 CORS define quais sites podem chamar sua API

Durante desenvolvimento

Terminalnpm install cors
JavaScriptimport cors from 'cors'; app.use(cors({ origin: 'http://localhost:5173', methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'] }));

Regra prática

Postman e Bruno não dependem do CORS porque não são páginas web. Já um frontend no navegador é bloqueado quando a API não autoriza sua origem.

Em produção, substitua * por domínios conhecidos e configure credenciais conscientemente.

  4. POST /tarefas: crie tarefa.

📝 Exercício 2 — CRUD em memória

Rotas

  • GET /tarefas lista o array.
  • POST /tarefas cria com título obrigatório.
  • PATCH /tarefas/:id altera concluída.
  • DELETE /tarefas/:id remove e retorna 204.

Regras

  • Use ids numéricos únicos.
  • Retorne 400 para título ausente.
  • Retorne 404 para id inexistente.
  • Teste cada rota no Postman ou Bruno.

✅ Gabarito 2 — POST com validação

JavaScriptconst tarefas = []; let proximoId = 1; app.post('/tarefas', (req, res) => { const titulo = req.body.titulo?.trim(); if (!titulo) { return res.status(400).json({ error: 'TITLE_REQUIRED' }); } const tarefa = { id: proximoId++, titulo, concluida: false }; tarefas.push(tarefa); return res.status(201).json(tarefa); }); app.get('/tarefas', (req, res) => res.json(tarefas));

Prossiga implementando PATCH e DELETE com a mesma regra: localizar, retornar 404 se necessário, alterar/remover e responder o status correto.

📝 Exercício 3 — Proteja uma rota

Situação

A turma não pode acessar a lista de tarefas sem login. A rota recebe Authorization: Bearer TOKEN.

Tarefa

  1. Crie middleware que rejeite header ausente com 401.
  2. Decodifique um JWT válido.
  3. Guarde o usuário em req.user.
  4. Aplique o middleware em GET /tarefas.

Reflexão

Por que o token não deve ser lido apenas pelo frontend? Por que uma tarefa deve ser filtrada por usuario_id também no SQL?

✅ Gabarito 3 — Middleware de token

JavaScriptfunction autenticar(req, res, next) { const header = req.headers.authorization; if (!header?.startsWith('Bearer ')) { return res.status(401).json({ error: 'TOKEN_REQUIRED' }); } try { req.user = jwt.verify(header.slice(7), process.env.JWT_SECRET); return next(); } catch { return res.status(401).json({ error: 'TOKEN_INVALID' }); } } app.get('/tarefas', autenticar, listarTarefas);
