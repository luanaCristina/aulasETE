🪞 Autoconhecimento — Quem Sou Eu?

Antes de planejar o futuro, é preciso entender suas forças, valores e motivações.

🧠 Ferramentas de Autoconhecimento

  • Ikigai: O que amo + sou bom + posso ser pago + mundo precisa
  • SWOT Pessoal: Forças, Fraquezas, Oportunidades, Ameaças
  • Valores Top 5: O que é inegociável na sua carreira?
  • Perfil DISC: Dominância, Influência, Estabilidade, Conformidade

💬 Perguntas-Chave

  • O que me faz perder a noção do tempo?
  • Que problema do mundo me incomoda?
  • Onde quero estar em 5 anos?
  • Que tipo de rotina me energiza?
  • O que faria mesmo sem ser pago?
💡 Não existe resposta errada — existe resposta honesta.

🔗 LinkedIn & GitHub — Seu Portfólio Digital

Recrutadores buscam candidatos online ANTES da entrevista. Esteja preparado.

💼 LinkedIn — Checklist

  • ✅ Foto profissional (rosto nítido)
  • ✅ Headline: "Estudante de Dev | React Native"
  • ✅ Sobre: 3 parágrafos (quem sou, o que faço, o que busco)
  • ✅ Experiências: projetos da escola contam!
  • ✅ Competências: listar tecnologias
  • ✅ Publicar 1x por semana (aprendizados)

🐙 GitHub — Checklist

  • ✅ README de perfil personalizado
  • ✅ Mínimo 5 repositórios públicos
  • ✅ READMEs com: descrição, screenshots, stack
  • ✅ Commits frequentes (gráfico verde)
  • ✅ Projetos pinados estrategicamente
  • ✅ Contribuição open source (bonus)
⚠️ Atenção: Seu GitHub é seu currículo vivo. Código mal organizado ou sem README causa impressão negativa.

🤝 Soft Skills — O Diferencial em TI

Hard skills te contratam. Soft skills te promovem e te mantêm empregado.

💬 Comunicação

  • Explicar código para não-devs
  • Documentar decisões técnicas
  • Dar e receber feedback
  • Apresentar ideias com clareza

🧩 Trabalho em Equipe

  • Git: branches e pull requests
  • Code review construtivo
  • Daily standup (Scrum)
  • Empatia com o colega

🧠 Resolução de Problemas

  • Debugging metódico
  • Pesquisar antes de perguntar
  • Pensamento crítico
  • Adaptabilidade a mudanças
💡 Dado: 92% dos recrutadores dizem que soft skills são tão importantes quanto hard skills (LinkedIn Talent Report 2024).

🎤 Elevator Pitch

Apresente-se profissionalmente em 60 segundos.

Estrutura: Quem sou → O que faço → O que busco → Call to action

🎯 Exemplo: "Oi, sou [Nome], estudante de Desenvolvimento de Sistemas na ETE. Desenvolvo apps mobile com React Native e tenho paixão por UX acessível. Estou buscando um estágio onde eu possa crescer como dev mobile. Posso te mostrar meu portfólio?"

📝 Exercícios — Simulação de Entrevista

🎯 Perguntas Clássicas

  1. "Me fale sobre você" (1-2 min)
  2. "Por que quer trabalhar com TI?"
  3. "Qual seu maior defeito?"
  4. "Conte um desafio que superou"
  5. "Onde se vê em 5 anos?"
  6. "Por que devemos te contratar?"
💡 Use o método STAR: Situação → Tarefa → Ação → Resultado

Critérios de avaliação:

  • Clareza e objetividade

  • Exemplos concretos (STAR)
  • Autenticidade

🚀 Projeto Final — Plano 5 Anos

Construa um roadmap pessoal e profissional para os próximos 5 anos.

📋 Estrutura do Plano

  • Ano 1: Conclusão do curso técnico + estágio
  • Ano 2: Primeiro emprego + certificações
  • Ano 3: Especialização + faculdade (EAD?)
  • Ano 4: Promoção ou transição de área
  • Ano 5: Meta salarial + projeto pessoal

📦 Entregáveis

  • Diagrama Ikigai preenchido
  • SWOT pessoal atualizado
  • Roadmap visual (timeline)
  • LinkedIn e GitHub otimizados
  • Elevator Pitch gravado (60s)
  • Pitch final (5 min, apresentado em sala)
