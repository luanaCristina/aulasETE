🔍 Vetor vs. Raster — Qual a Diferença?

Entender a diferença fundamental entre imagens vetoriais e bitmap é o primeiro passo.

CritérioVetor (SVG, AI)Raster (PNG, JPG)
ComposiçãoFórmulas matemáticas (pontos, curvas)Grade de pixels coloridos
Escala♾️ Sem perda de qualidade❌ Pixela ao ampliar
Tamanho de arquivoLeve (formas simples)Pesado (muitos pixels)
Ideal paraÍcones, logos, UI, animaçõesFotos, texturas complexas
EditabilidadeCada elemento é um objetoPixels individuais
FerramentasInkscape, Figma, IllustratorGIMP, Photoshop, Canva
💡 Regra prática: Se a imagem é feita de formas geométricas e precisa escalar → Vetor. Se é uma foto real com milhões de cores → Raster.

🛠️ Ferramentas — Inkscape & Figma

🖊️ Inkscape (Desktop)

  • Gratuito e open source
  • Melhor para SVG detalhado
  • Paths avançados e Bézier
  • Exportação SVG limpa
  • Ideal para ilustrações complexas

📥 Download: inkscape.org

🎨 Figma (Web/Desktop)

  • Gratuito para estudantes
  • Colaboração em tempo real
  • Componentes reutilizáveis
  • Auto-layout e variantes
  • Exportação multi-formato

🌐 Acesso: figma.com (navegador)

🎯 Na prática: Use Inkscape para criar SVGs detalhados → importe no Figma para montar o design system → exporte para o código.

📐 Princípios — Geometria e Grid

Todo ícone profissional começa com um grid base e formas geométricas simples.

📏 Grid de Ícones (24x24)

  • Live area: 20x20px (centro)
  • Padding: 2px em cada lado
  • Stroke: 2px consistente
  • Cantos: Border-radius 2px
  • Ângulos: 45° ou 90° preferíveis

🔷 Formas Primitivas

  • Círculo → Perfil, notificação
  • Quadrado → Card, calendário
  • Triângulo → Play, setas
  • Retângulo → Listas, menus
  • Combinações → Complexidade

"Simplifique até não poder remover mais nada."

⚠️ Consistência: Todos os ícones de um set devem usar o MESMO grid, peso de stroke e estilo (outline ou filled).
