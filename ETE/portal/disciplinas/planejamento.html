🧠 Lógica de Programação — Conceitos e Código

80h · Módulo 1 · A BASE de tudo

Conceitos Fundamentais

  • Algoritmo = receita de bolo (passo a passo para resolver um problema)
  • Variável = caixa etiquetada (guarda um valor com um nome)
  • Tipos primitivos: number, string, boolean
  • Condicionais: if/else = tomada de decisão
  • Loops: for/while = repetição até condição ser atendida

Código Exemplo

JavaScript// Variáveis e tipos let nome = "Maria"; // string let idade = 17; // number let aprovado = true; // boolean // Condicional if (idade >= 18) { console.log("Adulto"); } else { console.log("Menor de idade"); } // Loop somando array const notas = [8, 7, 9, 6]; let soma = 0; for (let i = 0; i < notas.length; i++) { soma += notas[i]; } console.log("Média:", soma / notas.length);
💡 Lógica é a BASE de tudo. Sem ela, nenhuma linguagem faz sentido.

🏗️ POO — Conceitos e Código

Analogias

  • Objeto = casa construída (instância)

4 Pilares

PilarExemplo
Encapsulamentosaldo é private, acessa via getSaldo()
HerançaDog extends Animal
Polimorfismoanimal.falar() → "Au au" ou "Miau"
Abstraçãoclass Forma é abstrata, Circulo implementa

Código Exemplo

TypeScriptclass Animal { protected nome: string; constructor(nome: string) { this.nome = nome; } falar(): string { return `${this.nome} faz som`; } } class Dog extends Animal { falar(): string { return `${this.nome} diz: Au au!`; } } class Cat extends Animal { falar(): string { return `${this.nome} diz: Miau!`; } } const pets: Animal[] = [ new Dog("Rex"), new Cat("Mimi") ]; pets.forEach(p => console.log(p.falar())); // Rex diz: Au au! // Mimi diz: Miau!

🗄️ Banco de Dados I — Conceitos e SQL

60h · Módulo 2 · Armazenar e consultar dados

Conceitos

  • Tabela = planilha com regras rígidas
  • PK (Primary Key) = CPF da tabela (identifica único)
  • FK (Foreign Key) = link entre tabelas
  • Normalização = evitar repetição de dados

DER Simplificado

Diagrama┌──────────┐ ┌──────────────┐ ┌─────────┐ │ ALUNO │ │ MATRICULA │ │ TURMA │ ├──────────┤ ├──────────────┤ ├─────────┤ │ id (PK) │──┐ │ id (PK) │ ┌──│ id (PK) │ │ nome │ └─→│ aluno_id (FK)│ │ │ nome │ │ email │ │ turma_id (FK)│←─┘ │ ano │ └──────────┘ │ data │ └─────────┘ └──────────────┘

SQL Essencial

SQL-- Criar tabela CREATE TABLE alunos ( id SERIAL PRIMARY KEY, nome VARCHAR(100) NOT NULL, email VARCHAR(150) UNIQUE, turma_id INT REFERENCES turmas(id) ); -- Inserir dados INSERT INTO alunos (nome, email, turma_id) VALUES ('Maria', 'maria@email.com', 1); -- Consulta com JOIN SELECT a.nome, t.nome AS turma FROM alunos a JOIN turmas t ON a.turma_id = t.id WHERE t.ano = 2026; -- Agrupamento SELECT turma_id, AVG(nota) AS media FROM notas GROUP BY turma_id HAVING AVG(nota) > 7;

📝 TCC — Exercícios Práticos

Ex1 — Definir Escopo

Escrever 1 parágrafo definindo o que o sistema FAZ e o que NÃO faz:

ExemploO sistema "AgendaFácil" permite que pacientes agendem consultas médicas online, escolhendo especialidade, médico e horário disponível. O sistema NÃO realiza teleconsulta, NÃO processa pagamentos e NÃO integra com planos de saúde nesta primeira versão.

Ex2 — Backlog com MoSCoW

Criar backlog com 10 User Stories priorizadas:

  • Must have (obrigatório para funcionar)
  • Should have (importante, mas não bloqueia)
  • Could have (bom ter, se der tempo)
  • Won't have (não nesta versão)

Ex3 — Pitch de 5 Minutos

Montar apresentação com esta estrutura:

  1. Problema (1 min) — Qual dor? Quem sofre?
  2. Demo (2 min) — Mostrar funcionando
  3. Arquitetura (1 min) — Stack + diagrama
  4. Aprendizados (1 min) — O que aprendeu? O que faria diferente?
