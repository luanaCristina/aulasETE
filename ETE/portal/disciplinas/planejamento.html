Total: 900 horas distribuídas em 4 semestres (2 anos)

🧱 Módulo 1 — Fundamentos (220h)

Semestre 1 — Base sólida para tudo que vem depois

🧠 Lógica e Pensamento Computacional — 80h

  • Variáveis, tipos, operadores
  • Estruturas condicionais e repetição
  • Arrays, objetos, funções
  • Algoritmos e resolução de problemas

🌐 HTML, CSS e Web Design — 60h

  • Semântica HTML5
  • Flexbox, Grid, Responsividade
  • Formulários e validação
  • Publicação (GitHub Pages)

🔌 Redes e Sistemas Operacionais — 40h

  • Modelo OSI/TCP-IP
  • Endereçamento IP, DNS, portas
  • Terminal Linux e comandos básicos

🎨 UI/UX e Design de Interfaces — 40h

  • Personas e jornada do usuário
  • Wireframes e protótipos (Figma)
  • Heurísticas de Nielsen

⚙️ Módulo 2 — Desenvolvimento (240h)

Semestre 2 — Programação profissional e banco de dados

🏗️ Programação Orientada a Objetos — 80h

  • Classes, herança, polimorfismo
  • Encapsulamento e abstração
  • Design Patterns introdutórios
  • Projeto: sistema de gestão com POO

🗄️ Banco de Dados I — 60h

  • Modelagem ER
  • SQL: DDL, DML, DQL
  • Joins, subconsultas, views
  • PostgreSQL + pgAdmin

🟡 JavaScript Frontend — 60h

  • DOM, eventos, fetch API
  • Async/await, promises
  • Componentização e SPA básico

📐 Engenharia de Software — 40h

  • Metodologias ágeis (Scrum/Kanban)
  • Requisitos, UML básico
  • Versionamento com Git

🚀 Módulo 3 — Profissionalização (200h)

Semestre 3 — Backend, qualidade e segurança

🔗 Backend e APIs REST — 80h

  • Node.js + Express
  • Rotas, controllers, middlewares
  • Autenticação JWT
  • Integração com banco de dados

☁️ Banco de Dados II (Cloud) — 40h

  • NoSQL (MongoDB/Firebase)
  • Banco na nuvem (Supabase, Neon)
  • Migrations e versionamento de schema

🧪 Testes e Qualidade — 40h

  • Testes unitários (Jest)
  • Testes de integração
  • TDD e cobertura de código

🔒 Segurança da Informação — 40h

  • OWASP Top 10
  • SQL Injection, XSS, CSRF
  • HTTPS, hashing, criptografia

🎓 Módulo 4 — Consolidação (180h)

Semestre 4 — Mobile, DevOps e TCC

📱 Desenvolvimento Mobile — 60h

  • React Native / Expo
  • Navegação, formulários, listas
  • Consumo de APIs no app
  • Publicação na Play Store

🐳 DevOps e Deploy — 40h

  • Docker e containers
  • CI/CD (GitHub Actions)
  • Deploy em cloud (Vercel, Render)
  • Monitoramento básico

📝 Projeto Final (TCC) — 80h

  • Problema real escolhido pelo aluno
  • Aplicação fullstack funcional
  • Documentação técnica completa
  • Apresentação pública (banca)
  • Código no GitHub + deploy funcional

🧩 Metodologia PBL — Aprendizagem Baseada em Projetos

🔄 Ciclo do Problema

  1. Problema real é apresentado
  2. Alunos identificam o que não sabem
  3. Pesquisa e estudo autodirigido
  4. Discussão em grupo e síntese
  5. Implementação da solução
  6. Apresentação e reflexão

🏫 Na Prática em Sala

  • Cada módulo = 1 projeto integrador
  • Sprints semanais com entregas parciais
  • Professora como facilitadora, não palestrante
  • Alunos aprendem pesquisando e fazendo
  • Erros são parte do processo
  • Trabalho em equipe simulando empresa
💡 "Não vou ensinar tudo — vou ensinar vocês a APRENDEREM tudo."

✅ Critérios de Aprovação

  • Média final ≥ 6,0
  • Frequência ≥ 75%
  • Projeto funcional entregue
  • Nenhuma competência com nota zero

🔄 Recuperação

  • Prova substitutiva por AV
  • Reentrega de projeto com correções
  • Prazo: até 1 semana após resultado
  • Nota máxima na recuperação: 8,0

🖥️ Infraestrutura e Ferramentas Necessárias

🏫 O que a Escola Precisa

  • Laboratório com mínimo 20 PCs
  • Internet estável (≥ 50 Mbps)
  • Projetor ou TV em cada sala
  • Permissão para instalar software
  • Acesso a GitHub (não bloqueado)
  • Ar-condicionado (conforto p/ 4h)

🛠️ Software Obrigatório (Gratuito)

  • VS Code (editor principal)
  • Node.js 20+ e Python 3.12+
  • PostgreSQL 16 + pgAdmin
  • Git + conta GitHub
  • Figma (conta educacional)
  • Docker Desktop
