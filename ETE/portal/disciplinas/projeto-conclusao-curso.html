🔍 Visão Geral: AgendaPro

O PCC é um produto único e evolutivo — o AgendaPro — que cresce a cada módulo do curso.

📱 O que é o AgendaPro?

Sistema de agendamento de consultas médicas que evolui em complexidade:

  1. Módulo 1: CLI Python + PostgreSQL
  2. Módulo 2: API REST Node.js + Frontend Web
  3. Módulo 3: TypeScript + React + Deploy Cloud

🎯 Por que evolutivo?

  • Simula a realidade: software cresce com o tempo
  • Cada módulo agrega valor ao anterior
  • Portfólio profissional no GitHub
  • Apresentação final = Demo Day com banca
💡 Mesmo projeto, 3 tecnologias, 1 portfólio completo.

🐍 Módulo 1: Python CLI + PostgreSQL

Semanas 1-20 — Fundação do sistema

📦 Entregas

  • DER com mín. 6 tabelas (pacientes, médicos, consultas, especialidades, horários, convênios)
  • Script SQL: DDL + Seeds + Views
  • App Python CLI com menu interativo
  • CRUD completo de pacientes e consultas
  • Regras de negócio (conflito de horário, cancelamento)
  • README.md com prints do terminal

🛠️ Tecnologias

  • Python 3.12+
  • PostgreSQL 16
  • psycopg2 (conexão)
  • python-dotenv (variáveis)
  • Git + GitHub

✅ Critério de Aprovação

CRUD funcional + DER normalizado + README + commits frequentes

🌐 Módulo 2: API REST Node.js

Semanas 21-40 — Backend web + Frontend

📦 Entregas

  • API REST Express com todas as rotas do CLI
  • Autenticação JWT (login paciente/admin)
  • Frontend HTML/CSS/JS consumindo a API
  • Tela de agendamento com calendário
  • UML: Casos de Uso + Sequência
  • 5+ testes com Jest + Supertest
  • Deploy no Render (backend) + Vercel (front)

🛠️ Tecnologias

  • Node.js 20 LTS
  • Express 4.x
  • PostgreSQL (mesmo banco do M1)
  • JWT + bcrypt
  • HTML5 + CSS3 + Fetch API
  • Jest + Supertest

✅ Critério de Aprovação

API deployada + frontend responsivo + testes passando

⚛️ Módulo 3: TypeScript + React + Deploy

Semanas 41-60 — Versão profissional do AgendaPro

📦 Entregas

  • Migração da API para TypeScript strict
  • Frontend React com Vite + TypeScript
  • Design System com componentes reutilizáveis
  • Testes E2E com Cypress ou Playwright
  • CI/CD com GitHub Actions
  • Docker + Docker Compose
  • Monorepo organizado

🛠️ Tecnologias

  • TypeScript 5.x (strict mode)
  • React 18 + Vite
  • TailwindCSS ou CSS Modules
  • Zod (validação)
  • Docker + Compose
  • GitHub Actions (CI/CD)

✅ Critério de Aprovação

App full-stack TS deployado + CI/CD + Demo Day
