📱 Full-Stack Mobile — Expo + Firebase

🏗️ Arquitetura

  • Frontend: React Native + Expo SDK 51
  • Backend: Firebase (Auth, Firestore, Storage)
  • Navegação: Expo Router (file-based)
  • Estado: Context API ou Zustand
Terminal # Criar projeto npx create-expo-app@latest meu-app cd meu-app # Instalar Firebase npx expo install firebase npm install @react-navigation/native

🔥 Setup Firebase

  1. Acesse console.firebase.google.com
  2. Crie projeto → Adicione app Web
  3. Copie as credenciais para firebaseConfig.ts
  4. Ative Authentication (Email/Google)
  5. Ative Firestore Database
firebaseConfig.ts import { initializeApp } from 'firebase/app'; const firebaseConfig = { apiKey: "sua-key", authDomain: "projeto.firebaseapp.com", projectId: "projeto-id", }; export const app = initializeApp(firebaseConfig);

🤖 Kiro + MCP — IA no Desenvolvimento

🛸 O que é Kiro?

  • IDE com IA integrada — assistente de código
  • Specs: Requirements → Design → Tasks
  • Steering: Regras do projeto que guiam a IA
  • Hooks: Automação de tarefas repetitivas

🔌 MCP — Model Context Protocol

  • Conecta a IA com ferramentas externas
  • GitHub, Jira, bancos de dados, APIs
  • Executa ações reais no seu ambiente

🔍 SEO Audit — Otimização para Buscadores

🏗️ Ferramentas

  • Lighthouse (Chrome DevTools → Audits)
  • PageSpeed Insights (web.dev/measure)
  • Meta Tag Inspector (extensão Chrome)
  • Screaming Frog (crawl de site)

📋 Checklist SEO Básico

  • ✅ <title> único por página (50-60 chars)
  • ✅ <meta name="description"> (150-160 chars)
  • ✅ Headings hierárquicos (h1 > h2 > h3)
  • ✅ Imagens com alt descritivo
  • ✅ URLs amigáveis (slugs)
  • ✅ Mobile-first responsive
  • ✅ HTTPS ativo

🏷️ Meta Tags Essenciais

HTML <head> <title>Minha Página | Site</title> <meta name="description" content="Descrição da página..."> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Open Graph (redes sociais) --> <meta property="og:title" content="Título"> <meta property="og:description" content="Descrição"> <meta property="og:image" content="url-da-imagem.jpg"> <!-- Robots --> <meta name="robots" content="index, follow"> </head>

🧬 Testes Unitários + Mutation Testing

🃏 Jest — Testes Unitários

soma.test.ts import { soma } from './soma'; describe('soma()', () => { it('deve somar dois positivos', () => { expect(soma(2, 3)).toBe(5); }); it('deve lidar com negativos', () => { expect(soma(-1, 1)).toBe(0); }); it('deve retornar 0 para inputs zero', () => { expect(soma(0, 0)).toBe(0); }); }); // Rodar: npx jest --coverage

🧬 Mutation Testing (Stryker)

Mutation testing verifica se seus testes realmente detectam bugs.

  • Modifica o código-fonte (mutantes)
  • Roda seus testes contra cada mutante
  • Se teste passa com mutante → teste fraco!
Terminal # Instalar Stryker npm install -D @stryker-mutator/core npm install -D @stryker-mutator/jest-runner # Configurar npx stryker init # Rodar npx stryker run
📊 Meta: Mutation Score > 80%
