🌐 Deploy — Publicando o Projeto

📱 Mobile (EAS Build)

  1. eas build:configure
  2. eas build --platform android --profile preview
  3. Baixar APK gerado
  4. Instalar no celular (QR code)
  5. Compartilhar link de download

Tempo: ~15 min na nuvem (grátis)

🌐 Web (Firebase Hosting / Vercel)

  1. npm install -g firebase-tools
  2. firebase init hosting
  3. firebase deploy
  4. URL pública: projeto.web.app

Alternativa — Vercel:

  1. Conectar repo GitHub
  2. Deploy automático a cada push
  3. URL: projeto.vercel.app
💡 CI/CD básico: Configure GitHub Actions para rodar npm test antes de cada deploy automático.
