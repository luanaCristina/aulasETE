🔍 O que é o Projeto Integrador I?

O PI1 é o projeto que conecta as disciplinas do Módulo 1 em uma entrega real e funcional.

🔗 Disciplinas Integradas

  • Banco de Dados — Modelagem e SQL
  • Python — Lógica e programação
  • Lógica Computacional — Algoritmos e estruturas

As 3 disciplinas convergem em UM produto.

🎯 Objetivo

Desenvolver uma aplicação CLI em Python que gerencia dados persistidos em PostgreSQL, aplicando algoritmos e estruturas de dados aprendidos em Lógica.

💡 O PI1 prova que você sabe construir software funcional de ponta a ponta.

⚙️ Metodologia: Scrum Adaptado

Usamos uma versão simplificada do Scrum para equipes de 3-4 pessoas.

📋 Cerimônias

  • Sprint Planning — Início de cada sprint (2 semanas)
  • Daily — 5 min no início da aula
  • Sprint Review — Demo a cada 2 semanas
  • Retrospectiva — O que melhorar?

🎭 Papéis

  • Product Owner — Define prioridades (rodízio)
  • Scrum Master — Facilita e remove blockers
  • Dev Team — Todos codam!

📊 Ferramentas

  • GitHub Projects (Kanban board)
  • Issues para cada tarefa
  • Commits descritivos em português

💡 Dicas e Erros Comuns

✅ Faça

  • Comece pelo DER — o banco guia o código
  • Faça commits diários (mesmo incompletos)
  • Use psycopg2 ou sqlalchemy para conexão
  • Trate TODAS as exceções do banco
  • Teste com dados reais (não apenas "teste123")
  • Peça feedback antes da semana 10

❌ Evite

  • Deixar tudo para a última semana
  • Código sem comentários ou docstrings
  • SQL injection (use parâmetros!)
  • Repositório sem .gitignore
  • Um membro faz tudo sozinho
  • README dizendo "projeto da escola"
💡 Dica de ouro: Se o DER estiver bom, o código praticamente se escreve sozinho. Invista tempo na modelagem!
