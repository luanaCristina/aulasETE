## 📖 Sobre a Disciplina

### Ementa

A disciplina de **Ilustração Vetorial** aborda os fundamentos da criação gráfica com vetores, capacitando o aluno a produzir materiais visuais profissionais para interfaces digitais, identidade visual e comunicação.

**Conteúdo programático:**

- Vetores vs Raster — diferenças fundamentais, quando usar cada formato
- SVG (Scalable Vector Graphics) — estrutura, vantagens para web
- Inkscape — interface completa, ferramentas de criação e edição de elementos gráficos
- Paths e Curvas de Bézier — controle preciso de formas vetoriais
- Tipografia — tipos de fonte, combinação (font pairing), hierarquia visual
- Criação de logotipos — princípios, processo criativo, variações
- Ícones para interfaces — consistência, grid, exportação
- Layouts web vetoriais — banners, headers, ilustrações flat

### Objetivos de Aprendizagem

Ao final da disciplina, o aluno será capaz de:

1. Diferenciar gráficos vetoriais e rasterizados, aplicando cada formato adequadamente
2. Utilizar o Inkscape com proficiência para criar ilustrações vetoriais
3. Manipular paths e curvas de Bézier com precisão
4. Aplicar princípios de tipografia em composições visuais
5. Desenvolver logotipos e sistemas de ícones coerentes
6. Exportar assets vetoriais otimizados para web e interfaces digitais
7. Criar identidade visual completa para projetos

## 🔧 Instalação do Inkscape

### Windows

1. Acesse o site oficial: [https://inkscape.org/release/](https://inkscape.org/release/)
2. Clique em **"Windows"** → baixe o instalador `.msi` (64-bit recomendado)
3. Execute o instalador e siga as instruções (Next → Next → Install)
4. Após instalação, abra o Inkscape pelo menu Iniciar

### macOS

1. Acesse: [https://inkscape.org/release/](https://inkscape.org/release/)
2. Clique em **"macOS"** → baixe o arquivo `.dmg`
3. Abra o `.dmg` e arraste o Inkscape para a pasta **Aplicações**
4. Na primeira abertura, clique com botão direito → "Abrir" (segurança do macOS)

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install inkscape
```

### Verificando a Instalação

- Abra o Inkscape
- Vá em **Ajuda → Sobre o Inkscape**
- Versão mínima recomendada: **1.3+**

> 💡 **Dica**: O Inkscape é 100% gratuito e open source. Não precisa de licença!

## 📚 Material Teórico

### 1. Vetor vs Raster — Tabela Comparativa

| Característica | Imagem Vetorial | Imagem Raster (Bitmap) |
|---|---|---|
| **Composição** | Pontos, linhas, curvas matemáticas | Pixels (grade de pontos coloridos) |
| **Escalabilidade** | ✅ Infinita sem perda de qualidade | ❌ Perde qualidade ao ampliar |
| **Tamanho do arquivo** | Geralmente menor (formas simples) | Pode ser muito grande (alta resolução) |
| **Edição** | Objetos individuais e editáveis | Edição por pixel |
| **Ideal para** | Logos, ícones, ilustrações, tipografia | Fotos, texturas, imagens complexas |
| **Formatos** | SVG, AI, EPS, PDF | PNG, JPG, GIF, TIFF, BMP |
| **Softwares** | Inkscape, Illustrator, Figma | Photoshop, GIMP, Krita |
| **Na web** | SVG (escalável, acessível, animável) | PNG/JPG (fotos, backgrounds) |
| **Cores** | Geralmente paleta limitada | Milhões de cores |
| **Resolução** | Independente de resolução | Depende de DPI/PPI |

### 2. Curvas de Bézier — Explicação

As **Curvas de Bézier** são a base da ilustração vetorial. São definidas matematicamente por pontos de controle:

```
Bézier Quadrática (3 pontos):
P(t) = (1-t)²·P0 + 2(1-t)t·P1 + t²·P2

Bézier Cúbica (4 pontos):
P(t) = (1-t)³·P0 + 3(1-t)²t·P1 + 3(1-t)t²·P2 + t³·P3
```

**Componentes:**
- **Ponto âncora (nó)**: onde a curva passa
- **Alça de controle**: define a direção e intensidade da curva
- **Tipos de nó**:
  - 🔵 **Suave**: alças opostas simétricas (curva contínua)
  - 🔴 **Cúspide**: alças independentes (ângulo)
  - 🟢 **Simétrico**: alças de mesmo comprimento e ângulo

**No Inkscape:**
- Ferramenta **Caneta** (B): criar paths ponto a ponto
- Ferramenta **Nó** (N): editar nós e alças existentes
- `Ctrl+Click`: criar nó reto (sem alça)
- `Click+Drag`: criar nó com alças (curva)

### 3. Princípios de Design de Logo

| Princípio | Descrição | Exemplo |
|---|---|---|
| **Simplicidade** | Formas mínimas, fácil de reconhecer | Nike (swoosh), Apple |
| **Memorabilidade** | Marcante, fácil de lembrar | McDonald's (arcos dourados) |
| **Versatilidade** | Funciona em qualquer tamanho e cor | Preto/branco funciona |
| **Atemporalidade** | Não segue modas passageiras | Coca-Cola (desde 1887) |
| **Relevância** | Conecta com o público-alvo | Toys "R" Us (infantil) |

**Processo de criação:**
1. 📋 **Briefing**: entender o cliente, valores, público
2. 🔍 **Pesquisa**: concorrentes, referências, mood board
3. ✏️ **Rascunhos**: 20-50 variações à mão
4. 💻 **Vetorização**: digitalizar os melhores no Inkscape
5. 🎨 **Refinamento**: cores, tipografia, variações
6. 📐 **Versões**: horizontal, vertical, ícone, monocromático

### 4. Exemplo de Código SVG

```xml
<?xml version="1.0" encoding="UTF-8"?>
<svg xmlns="http://www.w3.org/2000/svg" 
     viewBox="0 0 200 200" 
     width="200" height="200">
  
  <!-- Círculo de fundo -->
  <circle cx="100" cy="100" r="90" 
          fill="#4CAF50" opacity="0.9"/>
  
  <!-- Triângulo (path) -->
  <path d="M100 30 L170 150 L30 150 Z" 
        fill="none" stroke="white" stroke-width="4"/>
  
  <!-- Texto -->
  <text x="100" y="185" 
        text-anchor="middle" 
        font-family="Arial, sans-serif" 
        font-size="14" fill="#333">
    Meu Logo SVG
  </text>
  
</svg>
```

**Estrutura do SVG:**
- `<svg>`: elemento raiz com namespace e viewBox
- `viewBox="0 0 200 200"`: sistema de coordenadas interno
- `<circle>`, `<rect>`, `<ellipse>`: formas primitivas
- `<path d="...">`: formas complexas com comandos (M, L, C, Z)
- `<text>`: texto renderizado como vetor
- Atributos: `fill`, `stroke`, `stroke-width`, `opacity`

## ✏️ Exercícios

### Exercício 1 — Recriação de Logo Simples
**Objetivo**: Reproduzir um logo famoso usando formas básicas no Inkscape.

**Instruções:**
1. Escolha um logo simples (Nike, Adidas, Target, Spotify)
2. Analise as formas geométricas que compõem o logo
3. Recrie usando apenas formas básicas e operações booleanas
4. Exporte em SVG e PNG (transparente)

**Entrega**: Arquivo `.svg` + captura de tela do processo

**Critérios de avaliação:**
- Proporções corretas (3 pts)
- Uso adequado de ferramentas (3 pts)
- Cores fiéis ao original (2 pts)
- Arquivo limpo e organizado (2 pts)

---

### Exercício 2 — Set de Ícones (6 ícones)
**Objetivo**: Criar um conjunto coerente de ícones para navegação.

**Instruções:**
1. Defina um grid de 24×24px como base
2. Crie 6 ícones: Home, Busca, Usuário, Configurações, Notificação, Menu
3. Mantenha consistência: mesmo peso de traço, mesmo estilo (outline ou filled)
4. Use no máximo 2 cores

**Entrega**: Arquivo `.svg` com todos os ícones + exportação individual PNG

**Critérios de avaliação:**
- Consistência visual entre ícones (4 pts)
- Uso correto do grid (2 pts)
- Clareza e reconhecimento (2 pts)
- Exportação correta (2 pts)

---

### Exercício 3 — Cartão de Visita
**Objetivo**: Design completo de um cartão de visita profissional.

**Instruções:**
1. Dimensões: 90mm × 50mm (frente e verso)
2. Crie um mini-logo ou monograma
3. Aplique hierarquia tipográfica (nome > cargo > contato)
4. Use no máximo 3 cores e 2 fontes
5. Inclua: nome, cargo, email, telefone, LinkedIn

**Entrega**: Arquivo `.svg` + PDF para impressão (CMYK se possível)

**Critérios de avaliação:**
- Hierarquia visual clara (3 pts)
- Escolha tipográfica adequada (2 pts)
- Uso do espaço (equilíbrio) (2 pts)
- Qualidade técnica para impressão (3 pts)

---

### Exercício 4 — Poster Tipográfico
**Objetivo**: Criar um poster usando APENAS tipografia como elemento visual.

**Instruções:**
1. Escolha uma frase inspiradora (máx. 15 palavras)
2. Tamanho A3 (297mm × 420mm)
3. Use hierarquia: palavra principal grande, resto menor
4. Máximo 3 fontes, mínimo 3 tamanhos diferentes
5. Pode usar texto em path, rotação, escala

**Entrega**: Arquivo `.svg` + PNG de alta resolução

**Critérios de avaliação:**
- Impacto visual (3 pts)
- Hierarquia e legibilidade (3 pts)
- Criatividade na composição (2 pts)
- Uso técnico das ferramentas (2 pts)

---

### Exercício 5 — Ícone de Aplicativo
**Objetivo**: Criar um ícone de app para dispositivos móveis.

**Instruções:**
1. Canvas: 1024×1024px (tamanho Apple App Store)
2. Crie um ícone para um app fictício (escolha o tema)
3. Deve funcionar em tamanho pequeno (48px)
4. Use cantos arredondados (20% do tamanho)
5. Máximo 4 cores + 1 gradiente

**Entrega**: SVG original + PNGs em 1024px, 512px, 192px, 48px

**Critérios de avaliação:**
- Reconhecível em tamanho pequeno (3 pts)
- Uso efetivo de cores e formas (3 pts)
- Originalidade (2 pts)
- Exportação multi-tamanho correta (2 pts)

#### Atividade B1: "Ícones em Grid"

| Item | Descrição |
|------|-----------|
| **Tema** | Consistência visual em design de ícones |
| **Duração** | 40 minutos |
| **Materiais** | Papel quadriculado (5mm), lápis, caneta preta fina, borracha |
| **Objetivo** | Desenhar ícones de app mantendo consistência de grid e espessura |

**📋 Roteiro do Professor:**
1. (10 min) Explicar no quadro: grid de ícones (24×24), área segura, espessura de traço consistente, cantos arredondados
2. (5 min) Mostrar exemplos impressos de ícones Material Design e suas construções no grid
3. (20 min) Alunos desenham 4 ícones (Home, Busca, Perfil, Config) no papel quadriculado usando o grid como guia
4. (5 min) Troca entre colegas: avaliar se os ícones parecem "da mesma família"

**📱 Guia do Aluno:**
- Use o papel quadriculado como seu grid (cada quadrado = 1 unidade)
- Defina área de desenho: 12×12 quadrados para cada ícone

- Use MESMA espessura de traço em todos os ícones (2 quadrados de largura)

#### Atividade B3: "Anatomia do SVG"

| Item | Descrição |
|------|-----------|
| **Tema** | Entendimento da estrutura do código SVG |
| **Duração** | 40 minutos |
| **Materiais** | Código SVG impresso (3-4 exemplos), lápis de cor, folha quadriculada |
| **Objetivo** | Identificar o que cada tag SVG faz e desenhar o resultado manualmente |

**📋 Roteiro do Professor:**
1. (10 min) Revisar no quadro: sistema de coordenadas SVG (0,0 = canto superior esquerdo), tags básicas
2. (5 min) Distribuir folhas com 3 códigos SVG impressos
3. (20 min) Alunos leem o código e DESENHAM o resultado esperado no papel quadriculado
4. (5 min) Professor revela o render real — comparar com desenhos dos alunos

**📱 Guia do Aluno — Exemplo de código para interpretar:**
```xml
<svg viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="blue"/>
  <rect x="30" y="30" width="40" height="40" fill="red" opacity="0.5"/>
  <line x1="0" y1="0" x2="100" y2="100" stroke="green" stroke-width="3"/>
</svg>
```
- Desenhe em papel quadriculado (1 quadrado = 10 unidades)
- Use lápis de cor para representar fills
- Indique com setas: cx, cy, r, x, y, width, height

### 🅲 Opção C: Estudo de Caso / PBL (Problem-Based Learning)

> 🎯 **Ideal quando:** Aula geminada (2 horários seguidos) para debate aprofundado

#### Caso 1: "Como o Material Design criou 2.500+ ícones consistentes"

| Item | Descrição |
|------|-----------|
| **Foco** | Sistema de design e padronização em escala |
| **Formato** | Pesquisa + análise + proposta (40-50 min) |
| **Conexão** | Bloco 4 (design de ícones) e Bloco 5 (design systems) |

**Dinâmica:**
1. Professor apresenta: evolução dos Material Icons (2014→hoje), grid de construção, 5 estilos (outlined, filled, rounded, sharp, two-tone)
2. Pergunta geradora: "Como garantir que 2.500 ícones pareçam feitos pela mesma pessoa?"
3. Grupos de 4 analisam: grid de construção, peso de traço, área de desenho, formas-chave
4. Cada grupo propõe: "Se vocês fossem criar um icon set para a ETE, quais seriam as 5 regras inegociáveis?"

---

#### Caso 2: "Rebranding do Nubank — do roxo sólido ao gradiente"

| Item | Descrição |
|------|-----------|
| **Foco** | Evolução de identidade visual e decisões de design |
| **Formato** | Timeline + debate (40-50 min) |
| **Conexão** | Bloco 4 (design de logotipos) e Projeto Final |

**Dinâmica:**
1. Professor apresenta timeline visual: logo Nubank 2013 → 2016 → 2021 → atual
2. Perguntas: "O que mudou?", "Por que mudou?", "O roxo permaneceu — por quê?"
3. Debate: "Quando uma marca DEVE mudar seu logo?" vs "Quando NÃO deve?"
4. Exercício final: cada aluno sugere uma evolução para o logo que criou no Exercício 1 da disciplina

#### Caso 3: "SVG vs PNG na web — por que o Airbnb migrou"

| Item | Descrição |
|------|-----------|
| **Foco** | Performance web e escolha técnica de formato |
| **Formato** | Análise técnica + cálculos (40 min) |
| **Conexão** | Bloco 1 (vetor vs raster) e Bloco 5 (SVG para web) |

**Dinâmica:**
1. Dados apresentados: "Site do Airbnb tem 200+ ícones. Cada PNG @3x = 5KB. Cada SVG equivalente = 1KB."
2. Cálculos: economia total, impacto no carregamento, acessibilidade (alt text em SVG)
3. Debate: "Quando SVG NÃO é a melhor escolha?" (fotos, gradientes complexos, compatibilidade)
4. Grupos propõem: política de "quando usar SVG vs PNG" para seu projeto do semestre

### 📊 Rubrica de Avaliação Adaptada (Atividades sem Laboratório)

| Critério | Excelente (10-9) | Bom (8-7) | Regular (6-5) | Insuficiente (<5) |
|----------|-----------------|-----------|---------------|-------------------|
| **Compreensão conceitual** | Demonstra domínio de vetores/SVG/composição | Boa compreensão com pequenas lacunas | Compreensão superficial dos conceitos | Não demonstra compreensão |
| **Consistência visual** | Ícones/elementos parecem "da mesma família" | Boa consistência com pequenas variações | Inconsistente mas reconhecível | Sem coerência visual |
| **Precisão técnica** | Grid respeitado, proporções corretas, traços uniformes | Pequenos desvios de grid/proporção | Desvios perceptíveis | Sem atenção ao grid |
| **Criatividade/Originalidade** | Solução original e bem fundamentada | Solução boa e funcional | Solução genérica/copiada | Não apresenta solução |
| **Entrega/Documentação** | Completa, limpa, dentro do prazo | Completa com pequenos ajustes | Incompleta mas entregue | Não entregou |

> 💡 **Nota:** Atividades de contingência têm o **mesmo peso** das atividades regulares. Capacidade de pensar design sem software é competência profissional valorizada!
