### 1. Como a Web Funciona

#### O Modelo Cliente-Servidor

```
┌─────────────┐         REQUISIÇÃO HTTP          ┌─────────────┐
│             │ ──────────────────────────────▶  │             │
│   CLIENTE   │    GET /index.html HTTP/1.1      │  SERVIDOR   │
│ (Navegador) │    Host: www.exemplo.com         │    (Web)    │
│             │ ◀──────────────────────────────  │             │
│  Chrome,    │         RESPOSTA HTTP            │  Apache,    │
│  Firefox    │    HTTP/1.1 200 OK               │  Nginx      │
│             │    Content-Type: text/html        │             │
└─────────────┘                                  └─────────────┘
       │                                                │
       │            ┌─────────────┐                     │
       └───────────▶│   SERVIDOR  │◀────────────────────┘
                    │     DNS     │
                    │             │
                    │ Traduz nome │
                    │ para IP:    │
                    │ exemplo.com │
                    │ = 93.184.   │
                    │   216.34    │
                    └─────────────┘
```

#### Fluxo Completo de uma Requisição Web

1. **Usuário** digita `www.exemplo.com` no navegador
2. **DNS** traduz o domínio para um endereço IP (ex: `93.184.216.34`)
3. **Navegador** estabelece conexão TCP com o servidor
4. **Navegador** envia requisição HTTP (`GET /index.html`)
5. **Servidor** processa a requisição e localiza o arquivo
6. **Servidor** envia resposta HTTP com o conteúdo (HTML, CSS, imagens)
7. **Navegador** renderiza a página na tela do usuário

#### Métodos HTTP Mais Comuns

| Método | Uso |
|--------|-----|
| `GET` | Solicitar/buscar um recurso (página, imagem) |
| `POST` | Enviar dados ao servidor (formulários) |
| `PUT` | Atualizar um recurso existente |
| `DELETE` | Remover um recurso |

### 2. HTML5 Semântico

#### Estrutura Semântica de uma Página

```
┌──────────────────────────────────────────┐
│              <header>                     │
│   Logo + Navegação Principal             │
├──────────────────────────────────────────┤
│              <nav>                        │
│   Links de Navegação                     │
├────────────────────────┬─────────────────┤
│                        │                 │
│       <main>           │    <aside>      │
│                        │                 │
│  ┌──────────────────┐  │  Conteúdo       │
│  │   <section>      │  │  lateral,       │
│  │                  │  │  widgets,       │
│  │  ┌────────────┐  │  │  links          │
│  │  │ <article>  │  │  │  relacionados   │
│  │  │            │  │  │                 │
│  │  └────────────┘  │  │                 │
│  │                  │  │                 │
│  └──────────────────┘  │                 │
│                        │                 │
├────────────────────────┴─────────────────┤
│              <footer>                     │
│   Copyright, links, contato              │
└──────────────────────────────────────────┘
```

#### Exemplo Completo de Página Semântica

```html

            </article>
        </section>
    </main>

    <aside>
        <h3>Links Úteis</h3>
        <ul>
            <li><a href="#">Recurso 1</a></li>
            <li><a href="#">Recurso 2</a></li>
        </ul>
    </aside>

        <p>&copy; 2025 Meu Site. Todos os direitos reservados.</p>
    </footer>
```

### 4. CSS Box Model

#### Diagrama do Box Model

```
┌─────────────────────────────────────────────────────┐
│                    MARGIN                            │
│   ┌─────────────────────────────────────────────┐   │
│   │               BORDER                        │   │
│   │   ┌─────────────────────────────────────┐   │   │
│   │   │            PADDING                  │   │   │
│   │   │   ┌─────────────────────────────┐   │   │   │
│   │   │   │                             │   │   │   │
│   │   │   │         CONTENT             │   │   │   │
│   │   │   │     (largura × altura)      │   │   │   │
│   │   │   │                             │   │   │   │
│   │   │   └─────────────────────────────┘   │   │   │
│   │   │                                     │   │   │
│   │   └─────────────────────────────────────┘   │   │
│   │                                             │   │
│   └─────────────────────────────────────────────┘   │
│                                                     │
└─────────────────────────────────────────────────────┘

Largura Total = margin-left + border-left + padding-left + width + 
                padding-right + border-right + margin-right
```

#### Exemplo Prático do Box Model

```css
/* Reset básico */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box; /* Inclui padding e border no width */
}

/* Exemplo de card com box model visível */
.card {
    width: 300px;
    padding: 20px;
    border: 2px solid #333;
    margin: 15px auto;
    background-color: #f9f9f9;
    border-radius: 8px;
}

.card h2 {
    margin-bottom: 10px;
    padding-bottom: 10px;
    border-bottom: 1px solid #ddd;
}

.card p {
    margin-bottom: 15px;
    line-height: 1.6;
}

/* Diferença entre box-sizing */
.content-box {
    box-sizing: content-box; /* Padrão: width = só conteúdo */
    width: 300px;
    padding: 20px;
    border: 5px solid blue;
    /* Largura real: 300 + 40 + 10 = 350px */
}

.border-box {
    box-sizing: border-box; /* width = conteúdo + padding + border */
    width: 300px;
    padding: 20px;
    border: 5px solid red;
    /* Largura real: 300px (padding e border inclusos) */
}
```

### 5. CSS Flexbox

```

│  │Item 1│  │Item 2│  │Item 3│  │Item 4│       │
│  └──────┘  └──────┘  └──────┘  └──────┘       │

  ══════════▶ Main Axis (Eixo Principal)

┌──────────┐
│ ┌──────┐ │  │
│ │Item 1│ │  │
│ └──────┘ │  │ Main Axis
│ ┌──────┐ │  │ (Eixo Principal)
│ │Item 2│ │  │
│ └──────┘ │  ▼
│ ┌──────┐ │
│ │Item 3│ │
│ └──────┘ │
└──────────┘

═══════════════════════════════════════════════════════

flex-start:      │■ ■ ■ ·····················│

═══════════════════════════════════════════════════════

                 │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
                 └────────────────┘
```

### 📝 Opção B: Atividades Desplugadas (Unplugged)

> 💡 **Conceito:** Aprender HTML/CSS sem computador, usando papel, caixas, post-its e o próprio corpo como "navegador humano".

#### Atividade B1 — "HTML no Papel" 🟢

| Item | Detalhe |
|------|---------|
| **Objetivo** | Escrever código HTML à mão e validar mentalmente a estrutura |
| **Materiais** | Folha pautada + caneta azul (tags) e preta (conteúdo) |
| **Duração** | 35 minutos |
| **Semanas** | 1-4 |

**Roteiro da Professora:**
1. [5 min] Apresentar desafio: "Crie uma página com header, nav, main, footer"
2. [20 min] Alunos escrevem HTML completo no papel, com indentação
3. [10 min] Professora atua como "navegador humano" — lê o código do aluno e DESENHA no quadro como ficaria renderizado

**Guia do Aluno:**
> 🎯 Escreva o código HTML completo no papel. Use caneta AZUL para as tags e PRETA para o conteúdo. Cuidado com a indentação! A professora vai "renderizar" seu código no quadro.

---

#### Atividade B2 — "CSS Box Model com Caixas de Sapato" 🟢

| Item | Detalhe |
|------|---------|
| **Objetivo** | Entender visualmente margin, padding, border e content |
| **Materiais** | 3-4 caixas de tamanhos diferentes, fita colorida, papel |
| **Duração** | 25 minutos |
| **Semanas** | 9-10 |

**Roteiro da Professora:**
1. [5 min] Caixa menor = CONTENT (escrever "conteúdo" dentro)
2. [5 min] Espaço entre content e parede da caixa = PADDING (forrar com papel)
3. [5 min] Parede da caixa = BORDER (decorar com fita colorida)
4. [5 min] Espaço ENTRE caixas na mesa = MARGIN
5. [5 min] Demonstrar `box-sizing: border-box` vs `content-box` (medir com régua!)

**Guia do Aluno:**
> 🎯 Olhe para as caixas: o conteúdo é o que está DENTRO. O padding é o espaço entre o conteúdo e a parede. A parede É a border. O espaço entre caixas É a margin!

---

#### Atividade B3 — "Flexbox Humano" 🟡

| Item | Detalhe |
|------|---------|
| **Objetivo** | Entender propriedades Flexbox usando alunos como flex items |
| **Materiais** | Fita adesiva no chão (container), crachás numerados |
| **Duração** | 30 minutos |
| **Semanas** | 13-14 |

**Roteiro da Professora:**
1. [5 min] Marcar retângulo no chão com fita = `flex container`
2. [5 min] 5-6 alunos entram no container = `flex items`
3. Professora dá comandos CSS e alunos SE MOVEM:
   - `justify-content: center` → todos vão pro centro
   - `justify-content: space-between` → primeiro e último nas pontas, outros distribuídos
   - `align-items: flex-end` → todos vão pra borda de baixo
   - `flex-direction: column` → formam coluna vertical
   - `flex-wrap: wrap` → quando não cabem, descem pra próxima linha
4. [5 min] Alunos registram no caderno os comandos e posições

**Guia do Aluno:**
> 🎯 Vocês SÃO os flex-items! Quando a professora disser uma propriedade CSS, movam-se para a posição correta. Pensem: "onde eu ficaria se fosse um `<div>` dentro de um container flex?"

#### Atividade B4 — "Responsividade com Molduras" 🟡

| Item | Detalhe |
|------|---------|
| **Objetivo** | Entender como layouts se adaptam a diferentes tamanhos de tela |
| **Materiais** | 3 molduras de cartolina (celular 6cm, tablet 15cm, desktop 30cm), layout impresso |
| **Duração** | 35 minutos |
| **Semanas** | 15-16 |

**Roteiro da Professora:**
1. [5 min] Recortar 3 molduras de cartolina simulando viewports (mobile/tablet/desktop)
2. [10 min] Imprimir layout de site em papel A3 (versão desktop)
3. [15 min] Alunos posicionam molduras sobre o layout e REDESENHAM o que apareceria em cada viewport
4. [5 min] Discutir: "O que precisa mudar? O que esconde? O que reorganiza?"

**Guia do Aluno:**
> 🎯 Coloque a moldura de celular sobre o layout. O que CABE? O que precisa sumir? O que precisa virar coluna? Redesenhe para cada viewport!

#### Atividade B5 — "Grid com Post-its" 🟡

| Item | Detalhe |
|------|---------|
| **Objetivo** | Construir layouts CSS Grid posicionando elementos fisicamente |
| **Materiais** | Quadro branco com grade desenhada, post-its coloridos |
| **Duração** | 30 minutos |
| **Semanas** | 14-15 |

**Roteiro da Professora:**
1. [5 min] Desenhar grade no quadro (3 colunas × 4 linhas)
2. [5 min] Distribuir post-its: "Header", "Nav", "Main", "Aside", "Footer"
3. [15 min] Alunos vão ao quadro posicionar post-its usando `grid-area`
4. [5 min] Desafio: "E se a tela fosse celular? Reorganizem pra 1 coluna!"

**Guia do Aluno:**
> 🎯 Cada post-it é uma seção do site. Posicione-os na grade como se estivesse escrevendo `grid-template-areas`. Lembre: no celular, tudo vira 1 coluna!

### 💼 Opção C: Estudo de Caso / PBL (Problem-Based Learning)

> 💡 **Conceito:** Aprender HTML/CSS analisando decisões reais de front-end em empresas e governos.

#### Caso 1 — "Por que o site do gov.br foi redesenhado" (Acessibilidade)

| Item | Detalhe |
|------|---------|
| **Tema** | O governo brasileiro redesenhou todos os sites para padrão de acessibilidade (e-MAG) |
| **Conexão** | HTML semântico, atributos ARIA, alt, contraste, formulários acessíveis |
| **Duração** | 50 minutos |
| **Formato** | Análise comparativa + debate + proposta |

**Roteiro:**

4. [5 min] Compartilhar: quais regras se repetiram em todas as duplas?

#### Caso 2 — "Google pagou multa por site não-responsivo" (Mobile-First)

| Item | Detalhe |
|------|---------|

| **Conexão** | Media queries, viewport meta tag, design responsivo, mobile-first |
| **Duração** | 50 minutos |
| **Formato** | Apresentação + análise de sites + redesign em papel |

2. [15 min] Análise: mostrar 3 sites (responsivo, parcial, quebrado no mobile)
3. [20 min] Exercício: redesenhar no papel um site "quebrado" para funcionar no celular
4. [5 min] Apresentar soluções CSS que resolveriam (media queries, flex-wrap, etc.)

## 📌 Observações Importantes

- 📂 **Organização é fundamental:** todos os projetos devem seguir a estrutura de pastas ensinada em aula
- 💾 **Salve frequentemente:** use Ctrl+S no VS Code após cada alteração
- 🔍 **Use DevTools:** o Chrome DevTools (F12) é sua principal ferramenta de debug
- 📱 **Teste sempre:** verifique seu site em diferentes tamanhos de tela usando DevTools
- ♿ **Acessibilidade:** sempre use atributo `alt` em imagens e labels em formulários
- 🤝 **Colaboração:** ajude colegas, mas cada aluno deve entregar seu próprio código
- ❌ **Plágio:** cópia de código de colegas ou internet sem adaptação resultará em nota zero
- 📅 **Prazos:** entregas atrasadas perdem 1 ponto por dia de atraso (máx. 3 dias)
