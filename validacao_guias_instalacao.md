# Validação visual — Guias de Instalação

- A navegação local reconhece 34 quadros e atualiza o contador para `34 / 34` no encerramento.
- O quadro **GitHub Desktop: interface** apresenta o roteiro visual, a imagem-guia de publicação e a sequência `Changes → Commit to main → Push origin` em formato legível.
- O quadro **Python: instalar pela interface** apresenta a sequência visual de instalação, a orientação sobre PATH e a imagem-guia em tamanho legível.
- O quadro **PostgreSQL 16 + pgAdmin 4** apresenta instalação, verificação por terminal e uma imagem de apoio à configuração pela interface.
- Os recursos locais para Python, VS Code, Node.js, GitHub Desktop e Bruno foram incluídos em `ETE/portal/assets/guias-instalacao/`.
- O guia complementar foi consolidado em cinco quadros e apresenta um mapa por assunto, com links para a trilha detalhada como fonte principal de instruções.
